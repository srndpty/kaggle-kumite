# #003 Santander Customer Transaction Prediction 実験レポート

## 評価設計

2026-11-19 に公式データを取得し、ダミーの Late Submission が Public・Private ともに ROC AUC 0.50000 となることを確認した。学習 200,000 行の陽性率は 10.049%。特徴量に欠損・Inf がなく、学習行に完全重複がなかったため、seed 42 の層化 5-fold を使った。各行を 1 回ずつ検証し、結合した OOF 予測を採点した。出現回数、標準化、ビン境界の推定は各 fold の学習行だけで行った。

## 自力の仮説検証

| Run | 変更 | 比較基準 | OOF AUC | OOF 差 | 改善 fold |
|---|---|---|---:|---:|---:|
| E01 | 標準化した生値 + L2 ロジスティック回帰 | — | 0.85949 | — | — |
| E02 | 値の log 出現回数を追加 | E01 | 0.86503 | +0.00554 | 5/5 |
| E03 | 16 分位点ビンの one-hot に置換 | E01 | 0.88465 | +0.02516 | 5/5 |
| E04 | 深さ 1 の LightGBM | E01 | 0.86736 | +0.00787 | 5/5 |
| E05 | 最大深さを 3 に変更 | E04 | 0.88852 | +0.02116 | 5/5 |

E03 は変数ごとに区分的な効果を学ぶ加法モデルで、変数間の交互作用を導入せずに E01 を大きく上回った。深さ 1 の E04 も同じ方向に改善した。E05 の改善幅は当初の「小さい」という予想を上回った。深い木は変数間の交互作用と同一変数での複数分割の両方を許すため、それぞれの寄与はこの比較では特定できない。改善 fold 数は方向の一貫性を示す。fold 同士の学習行には重なりがある。

## 上位解法とアブレーション

E01〜E05 を実行してから、次の参加者本人の writeup を参照した。

- **1 位 Wizardry** は値の出現回数とクラス別の出現状況を特徴化し、単独出現値を平均で置き換えた列も追加した。変数ごとに処理する NN と LightGBM をブレンドした。 [本人の writeup](https://www.kaggle.com/competitions/santander-customer-transaction-prediction/discussion/89003)
- **2 位** は数値の丸め前後の出現頻度を使い、変数を縦持ちに変換して予測し、変数別の予測をオッズに変換して集約した。 [本人の writeup](https://www.kaggle.com/competitions/santander-customer-transaction-prediction/writeups/2nd-place-solution)
- **17 位 RAPIDS.ai** は単独出現値などをマスクした特徴や target encoding を木モデルに使い、NN ではクラス条件付き分布が似た変数間で重みを共有した。 [本人の writeup](https://www.kaggle.com/competitions/santander-customer-transaction-prediction/writeups/rapids-ai-rapids-ai-solution)

E06 では値のマスクだけを E01 に追加した。学習行は自身を除いた学習 fold に同値があるとき、検証・テスト行は学習 fold に同値があるときに、生値を追加列へ残す。それ以外の追加列の値は 0 とする。この設定で、テスト集合の頻度やラベルを使わずに反復有無で値の傾きを変えられるかを検証した。

E06 の OOF AUC は 0.86422。E01 比で +0.00473、5 fold 全てで改善した。出現回数そのものを追加した E02 は 0.86503 だった。E02 と E06 の差は 0.00081 で、両特徴の優劣は判断を保留した。

## 最終評価

最終候補は E05。OOF AUC が次点 E03 を 0.00387 上回り、事前に設定した 0.001 の再比較閾値を超えたため seed 42 で確定した。確定後の Late Submission は以下のとおり。

| Run | OOF AUC | Public | Private |
|---|---:|---:|---:|
| E01 Baseline | 0.85949 | 0.86096 | 0.86065 |
| E05 最終 | 0.88852 | 0.89250 | 0.88914 |
| E05 − E01 | +0.02903 | +0.03154 | +0.02849 |

Baseline からの改善方向は CV と外部評価で一致した。Private の改善幅は OOF より 0.00054 小さかった。

[選定監査記録](selection.json) は採点後に作成し、実験ログ上の提出 SHA256 と実ファイルを照合した。

## エラー分析

OOF の上位 10% を陽性側、下位 10% を陰性側の誤り集計に使った。各帯 20,000 行で、E05 は E01 に比べ上位帯の陰性数が 10,134 → 9,066、下位帯の陽性数が 92 → 44 に減った。

| 学習 fold で未出現だった特徴値の割合 | E01 上位帯の陰性数 / 行数 | E05 上位帯の陰性数 / 行数 | E01 下位帯の陽性数 / 行数 | E05 下位帯の陽性数 / 行数 |
|---|---:|---:|---:|---:|
| 25% 以下 | 66 / 107 | 35 / 74 | 0 / 161 | 1 / 227 |
| 25% 超〜30% | 2,151 / 3,966 | 1,531 / 3,360 | 19 / 4,544 | 8 / 5,498 |
| 30% 超〜35% | 6,098 / 12,005 | 5,407 / 11,972 | 50 / 12,008 | 28 / 11,768 |
| 35% 超〜40% | 1,769 / 3,805 | 2,021 / 4,436 | 22 / 3,208 | 7 / 2,467 |
| 40% 超 | 50 / 117 | 72 / 158 | 1 / 79 | 0 / 40 |

件数が最も多い 30% 超〜35% の帯では、上位帯の陰性の割合が 50.8% → 45.2%、下位帯の陽性の割合が 0.42% → 0.24% になった。順位帯に入る行はモデルによって変わる。両端の未出現率の帯は標本数が少なく、誤り率の傾向は保留した。
