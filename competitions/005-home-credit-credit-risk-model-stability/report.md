# #005 Home Credit - Credit Risk Model Stability 振り返り

## 評価環境

非公開 Notebook から定数 0.5 を提出（ID 58885518）し、Public・Private ともに 0.00000 だった。公式 Parquet の学習 1,526,659 行を使用し、過去申込の作成日を今回の判断日より前に限定した。

## 検証条件

週53–65、66–78、79–91を検証し、各窓の開始前の申込で学習する。週別 Gini の平均、低下傾向、ばらつきの3成分を窓ごとに計算する。ラベル確定遅延の長さは公式資料から特定できなかった。

## Baseline

E00 の3窓平均スコアは 0.50292。最初の窓は平均 Gini 0.56586、低下ペナルティ −0.20209、安定性スコア 0.35647 だった。第2・第3窓には低下ペナルティがなかった。

モデルを埋め込んだ提出 Notebook は Kaggle API が HTTP 400 で受け付けなかった。再試行 F-E00-r2 では、Kaggle 内で CV と同じ設定の全行再学習と推論を行った。提出 ID 58886234、Public 0.43314、Private 0.34425。

## 上位解法と追試

1位チームは履歴の各項目を複数の統計量で集約し、複数学習器を組み合わせた。13位チームは手作業と相関で特徴を選び、異なる学習器の予測をスタッキングした。E04 は1位チームの集約から、E01 に過去の融資額・カード限度額の最大値だけを追加する比較。作成日による打ち切りは E01 と共通。 [1位チームの本人解説](https://www.kaggle.com/competitions/home-credit-credit-risk-model-stability/writeups/yuuniee-1st-place-solution-my-betting-strategy) · [13位チームの本人解説](https://www.kaggle.com/competitions/home-credit-credit-risk-model-stability/writeups/team-dic-13th-place-solution-pmts-year-1139t-postp)

E04 の3窓スコアは 0.37550、0.55659、0.61008。3窓平均は 0.51406 で E01 から +0.00602。第1窓では平均週別 Gini は −0.00010 だったが、低下ペナルティが −0.20101 → −0.18260 になった。39週をまとめたスコアは 0.57108 で E01 の 0.57104 と近かった。

## 最終選定と誤差分析

3窓平均最大の E04 を選定した。週別 Gini の最小は第1窓で週64の 0.54414、第2窓で週69の 0.45871、第3窓で週81の 0.57137。

| 判断日前の履歴 | 検証行数 | 陽性率 | 平均予測 | 行を結合した Gini | Brier スコア |
|---|---:|---:|---:|---:|---:|
| なし | 69,443 | 2.127% | 2.382% | 0.46033 | 0.02013 |
| あり | 368,380 | 3.502% | 3.622% | 0.61574 | 0.03172 |

履歴なしの集団は識別力が低く、平均予測と陽性率の差が大きかった。Brier スコアは陽性率の違いも反映する。

## 最終外部評価

E04 を公式学習データ全 1,526,659 行で再学習し、F00 として提出した。公式サンプル10件で ID 順、有限性、確率範囲を確認した。Kaggle の最終提出 ID は 58886515。Public 0.44888、Private 0.36145 で、Baseline からそれぞれ +0.01574、+0.01720 だった。 [最終 Notebook](https://www.kaggle.com/code/shion5/kumite-home-credit-stability-e04)

CV の3窓平均は 0.51406 で、Private は 0.15261 低かった。CV は学習期間内の13週窓を個別に採点し、Private は公式テストの採点対象週で計算される。検証期間と採点対象の違いがスコア差にどの程度寄与したかは切り分けていない。
