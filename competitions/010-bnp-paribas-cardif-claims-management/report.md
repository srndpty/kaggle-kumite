# #010 BNP Paribas Cardif Claims Management 振り返り

## 上位解法

- 1 位 Dexter's Lab は、匿名数値列の関係から日付差と契約を推定し、同一契約に
  属すると見なした請求間のラベルの持続性を活用した。E04 ではラベルを使わず、
  近似的に単位をそろえた 2 列の差だけを E00 に追加した。 [本人解説](https://www.kaggle.com/competitions/bnp-paribas-cardif-claims-management/writeups/dexter-s-lab-1-dexter-s-lab-winning-solution)
- 5 位 the flying burrito brothers の SK が公開した担当コードでは、
  XGBoost、ランダムフォレスト、正則化線形モデルなど異なるモデルの出力を
  組み合わせていた。本実験では単一モデルで各変更の効果を測定した。 [本人公開コード](https://github.com/shachark/kaggle-bnp-paribas-cardif-claims-management/blob/master/bnp.r)

層化 CV は観測済みと同じ母集団から請求が来る場合の比較に使った。
上位解法の契約仮説に従うと、別請求の同一契約が fold をまたぐ可能性がある。
契約をまたぐ汎化や将来への汎化は、今回の CV と外部スコアからは判断できない。

## 自力の比較と最終評価

| run | OOF Log Loss | E00 との差 | 95% ペア bootstrap 区間 |
| --- | ---: | ---: | ---: |
| E00 | 0.473624 | 0 | — |
| E01 | 0.473412 | −0.000212 | [−0.000608, 0.000168] |
| E02 | 0.473885 | +0.000261 | [−0.000091, 0.000619] |
| E03 | 0.473723 | +0.000099 | [−0.000310, 0.000515] |
| E04 | 0.474063 | +0.000439 | [0.000098, 0.000789] |

E01 は OOF の点推定では最小で、欠損のある行の Log Loss は E00 の
0.459907 から 0.459589 に下がった。一方、欠損のない行では 0.548225 から
0.548587 に上がり、全行の区間はゼロを含んだ。E03 もカテゴリ欠損行で
0.457845 から 0.457902 に上がり、事前に予想した改善は観測できなかった。
E04 の近似差分は、この単独追加では悪化した。

選定には OOF のみを使用し、行のペア再標本化 2,000 回で差の 95% 区間が
全体に負の候補がなかったため E00 を採用した。再標本化は行の独立を仮定しており、
潜在的な同一契約や seed による変動の影響は未検証。

最終 E00 の Public は 0.47044、Private は 0.46881。OOF との差はそれぞれ
−0.00318 と −0.00481。OOF は各行で 1 モデル、提出は 5 fold 平均であり、
評価母集団の差もある。今回の結果から寄与を切り分けることはできない。

## 知見

欠損率が高い表でも、固定した LightGBM では扱いの変更による改善は確認できなかった。
条件と証跡は [K030](../../knowledge/K030-missing-value-ablation.md) に記録した。

## レビュー後の再検証

E03-r2 では各カテゴリ列に欠損用の値を予約し、学習 fold に欠損がない場合も
変換時の欠損と未知カテゴリを別コードにする。公式データでは、各 fold の学習側で
欠損がないカテゴリ列は 8 列あり、その列の検証・テスト側にも欠損は 0 件だった。
E03-r2 の OOF Log Loss は旧 E03 と同じ 0.473723。両 run の記録を保持し、
再監査でも E00 を採用した。 [選定の再監査](selection-review.json)
