# #011 Allstate Claims Severity 振り返り

固定した 5-fold GroupKFold の OOF で、目的変数を log1p 変換して L2 で学習した E02 を採用した。元尺度 L2 の E00 に対して MAE が 36.01 下がった。特徴量一致グループを再標本化したペアブートストラップ 2,000 回で、差の 95% 区間は [−38.64, −33.43]。最終提出の前に選定結果を保存した。 [選定記録](selection.json)

## 比較実験

| Run | 変更 | OOF MAE | E00 との差 | 改善 fold |
|---|---|---:|---:|---:|
| E00 | 元尺度 L2 | 1188.21 | 0.00 | — |
| E01 | 元尺度 L1 | 1159.18 | −29.02 | 5/5 |
| E02 | log1p 変換と L2 | 1152.20 | −36.01 | 5/5 |
| E03 | 平方根変換と L2 | 1153.58 | −34.63 | 5/5 |
| E04 | 元尺度 L2 にクラスタ距離を追加 | 1189.21 | +1.00 | 0/5 |

E01 は学習損失を評価指標と揃える仮説を支持した。E02 と E03 は、目的変数の右裾を圧縮する方法でも全体 MAE が改善することを示した。E02 と E03 の差は 1.38 で、事前ルールに従い最小 OOF の E02 を採用した。95% 区間は E00 との比較に対応する。

E04 では 2 位解法の距離特徴を、連続値 14 列、各 fold の学習側で標準化、16 個のクラスタ中心という条件で検証した。元尺度 L2 の LightGBM では改善を観測しなかった。 [2 位本人へのインタビュー](https://medium.com/kaggle-blog/allstate-claims-severity-competition-2nd-place-winners-interview-alexey-noskov-f4e4ce18fcfc)

## 損失帯ごとの誤差

| 実測損失帯 | E00 MAE | E01 MAE | E02 MAE | E03 MAE | E04 MAE |
|---|---:|---:|---:|---:|---:|
| 下位 25% | 856.20 | 645.72 | 620.83 | 728.53 | 856.96 |
| 中央 50% | 839.80 | 776.79 | 738.37 | 774.07 | 841.18 |
| 75〜99 パーセンタイル | 1983.64 | 2135.60 | 2239.70 | 2086.09 | 1983.81 |
| 上位 1% | 7815.20 | 9677.83 | 9024.00 | 8371.42 | 7823.86 |

- E02 は下位と中央の誤差を減らした。中央 50% の平均過大予測額は、過小予測を 0 として集計すると E00 の 579.54 から E02 の 358.29 に下がった。一方で、上位 1% の平均符号付き誤差は −7479.11 から −8922.38 に広がった。
- E03 の上位 1% の平均符号付き誤差は −8205.15 で、E02 より過小予測が小さかった。中央帯の平均過大予測額は 459.24 で、E00 と E02 の間に入った。
- 全体の MAE は行平均なので、小口・中口の改善が大口の悪化を上回った。大口の過小予測に追加の費用がある用途への適用は未検証。 [帯別の集計値](selection.json)

## 再現と知見

E00・E01 の実行時は、未知カテゴリをカテゴリ型へ直接変換する pandas の経路を使った。後続の run と現在のコードでは、未知カテゴリを明示的に欠損へ置換してから変換する。いずれも LightGBM への入力は未知カテゴリを欠損として扱う。現在のコードで E00 と E04 を再学習し、保存済みの OOF・テスト予測と完全一致することを確認した。公式 ZIP の直下の CSV を選ぶ手順と run の再実行方法は README に記載した。 [README](README.md)
