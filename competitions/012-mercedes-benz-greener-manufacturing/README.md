# #012 Mercedes-Benz Greener Manufacturing

深さは Standard。CPU で、小標本・高カーディナリティの表形式回帰を検証する。車両構成から試験時間を予測する。公式指標は決定係数 R²、提出列は `ID,y`。[Kaggle 公式概要](https://www.kaggle.com/c/mercedes-benz-greener-manufacturing)

## P0〜P2

公式データを取得し、訓練中央値 99.15 の定数予測をダミー提出した。訓練は4,209行、特徴量は376列。欠損はなく、カテゴリ8列の水準数は4〜47。目的変数の中央値は99.15、最大は265.32。ID と目的変数を除くと完全一致の2件目以降が298行ある。

同じ車両構成をグループにした5分割の `group-v1` で、同一構成の学習・検証間の重複を防ぐ。ID はモデルから除く。カテゴリ変換は fold の学習側だけで適合する。

## 自力仮説と事前予想

| Run | E00 からの変更 | OOF R² の予想 |
|---|---|---|
| E00 | one-hot と二値特徴を使う Ridge | 比較基準 |
| E01 | 学習 fold で5件未満のカテゴリを統合 | 希少水準の推定が安定して改善 |
| E02 | Ridge の alpha を10から100に変更 | 係数の過適合が減って改善 |
| E03 | 二値特徴を除外 | カテゴリにない構成情報を失って悪化 |
