# #012 Mercedes-Benz Greener Manufacturing 実験レポート

## 検証設計

ID と試験時間を除く全特徴の完全一致で3,911構成を識別し、同じ構成が学習側と検証側をまたがない5分割にした。テスト予測は5モデルの平均。分割にはラベルを使わず、one-hot は学習側で適合する。ID の四分位帯で目的変数平均は101.47、100.79、101.09、99.33、X5 の水準数は12、7、6、7だった。ID とともに分布が変わり得るが、ID が実際の試験順かは確認できていない。

## 比較実験

全4,209行の OOF を一括採点した。区間は E00 との差（比較 run の MSE − E00 の MSE）を車両構成ごとに2,000回ペアで再標本化した95%区間。採用条件は区間の上端が負であること。区間は固定した OOF 予測に基づき、分割や学習をやり直した場合の変動は含まない。

| Run | OOF R² | MAE | ΔMSE | 95%区間 |
|---|---:|---:|---:|---|
| E00 | 0.55461 | 5.44820 | — | — |
| E01 | 0.55397 | 5.45470 | +0.10219 | [0.02250, 0.19709] |
| E02 | 0.55489 | 5.42095 | −0.04514 | [−1.01384, 1.02925] |
| E03 | 0.54489 | 5.53840 | +1.56218 | [0.52084, 2.67799] |
| E04 | 0.55463 | 5.44817 | −0.00287 | [−0.00649, 0.00072] |

希少水準の統合は悪化した。強い正則化では点推定が少し改善したが、差は不確かだった。二値特徴の除外は5 fold すべてで悪化し、カテゴリを残しても二値特徴群に追加の予測情報があった。[知見 K015](../../knowledge/K015-feature-group-ablation.md)

## 上位解法と単独アブレーション

- 1位の gmobaz は、少数の特徴とその交互作用に着目し、木の重要度を使った特徴選択を経て2つの XGBoost モデルを平均した。本人の writeup が重視した組から X314 と X315 を選び、両方が1のときだけ立つ積を E00 に1列追加した。E04 の改善は不確かだった。この組は同じコンペの公開解法から選んでおり、新規データでの再現は未検証。 [1位本人の writeup](https://www.kaggle.com/competitions/mercedes-benz-greener-manufacturing/writeups/gmobaz-1st-place-solution)
- 6位の公開コードは、PCA・Truncated SVD などの射影特徴を使う XGBoost と、LassoLarsCV と勾配ブースティングを含むスタックを平均している。6位は投稿者のコンペ表示で確認した。こちらは手法の確認までとした。 [公開コード](https://www.kaggle.com/code/tobikaggle/stacked-then-averaged-models-0-5697) · [Kaggle の議論](https://www.kaggle.com/competitions/mercedes-benz-greener-manufacturing/discussion/36124)

## 最終評価と誤差

採用条件を満たす変更がなかったため E00 を採用した。採点済みの初回提出と同じ予測ファイルなので、その結果を最終外部評価に使った。Public R² は **0.54057**、Private R² は **0.53651**。どちらも OOF の 0.55461 を下回った。外部評価した学習モデルは E00 の1件で、モデル間順位の一致は検証できていない。

| OOF の対象 | 件数 | MAE | 平均誤差（予測 − 実測） |
|---|---:|---:|---:|
| 目的変数の上位5% | 211 | 22.40 | −22.40 |
| 学習 fold に未出現のカテゴリ水準を含む | 17 | 10.60 | −5.78 |
| 未出現はなく、出現1〜4件の水準を含む | 66 | 5.74 | −0.79 |
| 全カテゴリ水準が5件以上 | 4,126 | 5.42 | +0.02 |
| ID 第1四分位帯 | 1,053 | 5.51 | −0.10 |
| ID 第2四分位帯 | 1,052 | 5.38 | +0.01 |
| ID 第3四分位帯 | 1,052 | 6.18 | −0.00 |
| ID 第4四分位帯 | 1,052 | 4.73 | +0.03 |

全5設定で、再学習した OOF とテスト予測は保存済み配列に完全一致した。

目的変数の上位5%が OOF 二乗誤差の54.4%を占めた。長時間の試験を一貫して過小予測しており、ここでの誤差が R² に強く効いた。目的変数で切った診断なので、運用時に上側の行を事前に識別できるかは未検証。

## 再現と検査

リポジトリ直下から、各設定を未使用の run ID で実行する。元の run と設定の対応は `E00: baseline`、`E01: rare`、`E02: strong`、`E03: categorical`、`E04: interaction`。

```powershell
dev download 12
$src = 'competitions/012-mercedes-benz-greener-manufacturing/src'
$variants = 'baseline', 'rare', 'strong', 'categorical', 'interaction'
$ids = 0..4 | ForEach-Object { 'E{0:D2}-r2' -f $_ }
for ($i = 0; $i -lt $variants.Count; $i++) {
    uv run python "$src/train.py" --run-id $ids[$i] --variant $variants[$i]
    if ($LASTEXITCODE) { throw "学習に失敗しました" }
}
uv run python "$src/analyze.py" @ids
```

分析には E00〜E04 に対応する run ID を順に渡す。引数を省くと元の5件を比較する。監査は分割の再現性、車両構成の非交差、OOF の全行充足、予測の有限性、データ・分割・成果物のハッシュ、評価条件と実験設定、提出 CSV の列・ID 順・予測値を照合する。採用候補は確認済みの OOF 予測から再計算した R² で順位付けする。数値特徴が train/test の両方で 0/1 のみであることも確認する。

分析は既定で `outputs/selection.json` に選定結果を保存する。`--selection` で保存先を指定できる。[選定証跡](selection.json) は外部評価後のコードレビュー対応時に、E00〜E04 の保存済み予測から再作成した。
