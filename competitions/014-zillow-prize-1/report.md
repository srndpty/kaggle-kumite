# #014 Zillow Prize 振り返り

公式の `logerror` を予測する第1ラウンドのデータで、学習損失と将来取引の MAE の関係を確認した。
最終モデルは固定 CV で E04 に決めた。 [公式評価仕様](https://www.kaggle.com/competitions/zillow-prize-1/overview)

## データと評価

公式の取引は167,888件。年別物件スナップショットへの ID 結合率は100%で、同じ物件に複数の取引がある行は3.18%だった。
ラベルの中央値は0.00600、1・99パーセンタイルは −0.33114 と 0.49590、最小・最大は −4.65542 と 5.26300。
2017年1〜8月の72,812件を4つの連続した2か月窓で検証した。学習ラベルとカテゴリ辞書は各窓の開始日より前の取引に限った。
2017年の物件属性は同年10月公開のスナップショットなので、検証時点で利用できた属性を厳密に再現するには、より古い時点の物件データが必要になる。
[公式データ仕様](https://www.kaggle.com/c/zillow-prize-1/data)

## 実測結果

| Run | 変更 | 1–2月 | 3–4月 | 5–6月 | 7–8月 | OOF MAE |
|---|---|---:|---:|---:|---:|---:|
| median | 学習ラベルの中央値 | 0.07291 | 0.06898 | 0.06839 | 0.06872 | 0.06946 |
| E01 | 二乗誤差 | 0.07884 | 0.07280 | 0.07105 | 0.07076 | 0.07284 |
| E02 | 絶対誤差 | 0.07274 | 0.06868 | 0.06801 | 0.06830 | 0.06913 |
| E03 | 学習ラベルの両端をクリップ | 0.07529 | 0.07043 | 0.06956 | 0.06933 | 0.07077 |
| E04 | E02 に半減期365日の重み | 0.07265 | 0.06866 | 0.06798 | 0.06829 | 0.06909 |
| E05 | E01 に郵便番号別平均評価額を追加 | 0.07888 | 0.07283 | 0.07116 | 0.07071 | 0.07288 |

E02 は E01 から 0.00371 改善し、定数中央値も 0.00033 上回った。E03 は E01 より改善したが、中央値基準には届かなかった。
絶対誤差は条件付き中央値を目標にするため、極端値を大きく重み付けする二乗誤差とは学習の着地点が異なる。
E04 の E02 に対する差は −0.00003273、物件単位のペア bootstrap 2,000回の95%区間は
[−0.00005697, −0.00000910]。改善は小さく、後半への集中は観測されなかった。

### 物件属性の時点可用性に対する感度分析

税額と建物・土地・合計評価額の4列を外し、元と同じ学習設定と検証窓で比較した。

| Run | OOF MAE |
|---|---:|
| E02-no-tax | 0.06910974 |
| E04-no-tax | 0.06909068 |

E04 の順位は維持された。差は −0.00001906 まで縮まり、物件単位のペア bootstrap の95%区間
[−0.00004300, +0.00000433] はゼロを含んだ。税額・評価額を外した条件で直近重みの改善を確かめるには、さらに証拠が必要になる。
他の物件属性の時点可用性も残るため、元の CV と採用記録を保持した。

## 上位解法とアブレーション

- 17位の Gough チームは、売買の観測がない物件も含めた近傍特徴、制約付き類似度回帰、スタッキングを使用した。 [本人 writeup](https://www.kaggle.com/competitions/zillow-prize-1/writeups/gough-17th-place-solution)
- 23位の mlin は、月ごとの残差バイアスに着目し、対象月の二段階モデルと CatBoost を比較した。LightGBM 向けにカテゴリ別の数値平均も試した。E05 はこの着眼点を郵便番号別の平均評価額1列に限定し、各学習窓の取引だけで集計した。E01 比で MAE は 0.00004 悪化した。 [本人 writeup](https://www.kaggle.com/competitions/zillow-prize-1/writeups/mlin-share-some-insights-about-lightgbm-vs-catboos)

## 誤差分析

E04 は E01 に対し、検証した8か月すべてと Los Angeles・Orange・Ventura の3郡で MAE が低かった。
中央90%では 0.04214 → 0.03749、下側5%では 0.28397 → 0.27854、上側5%では 0.41420 → 0.42846。
全体の改善は主に中央の取引から得られ、大きな正の誤差がある物件では悪化した。

## 外部評価

| 提出 | Public MAE | Private MAE |
|---|---:|---:|
| E00 ゼロ予測 | 0.06630 | 0.07742 |
| E01 二乗誤差 | 0.06932 | 0.07915 |
| E04 CV 選定 | 0.06507 | 0.07543 |

E04 は E01 とゼロ予測の両方を Public・Private で上回った。絶対誤差単独の E02 の外部採点はないため、直近重み単独に関する証跡は CV に限られる。
実験ログの `late_score` は提出を生成した run の Private MAE。 [Kaggle 提出履歴](https://www.kaggle.com/competitions/zillow-prize-1/submissions)

E04 の再計測 `E04-r2` で OOF の SHA-256 が一致した。再選定でも同じ設定が選ばれ、`final-r2` の提出 CSV は `final-v1` とバイト単位で一致した。
提出の2,985,217件は公式雛形と ID 順・列順が一致し、全予測値が有限だった。
選定証跡の照合を追加した後も、`final-audited` の提出 CSV は両方と同じ SHA-256 だった。
