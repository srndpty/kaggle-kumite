# #016 PetFinder.my Adoption Prediction 振り返り

ペットの掲載情報から譲渡速度の5段階を予測し、QWK で評価した。**内側 OOF で閾値を調整した E03 を採用した。** OOF QWK は 0.37908 で、表特徴 Baseline E01 の 0.26455 から +0.11453。

## 検証

学習 14,993 行・公開テスト 3,972 行の保護者 ID に重複はなかった。学習側の保護者を、ファイル内容が完全一致する画像の共有で結合し、5,558 グループを得た。連結グループをまたがない層化5分割（seed 42）を固定した。すべての比較は同じ検証行を連結した OOF QWK で行う。

E01 は表特徴だけの CatBoost 多クラス分類。クラス確率の期待値を 0.5、1.5、2.5、3.5 で区切った。E03 の閾値は各外側学習部分の内側 OOF から決めた。提出では全学習データの OOF で閾値を決め、5モデルの連続予測の平均に適用する。

E02 の2段階以上の誤分類率は15.95%、E01 は15.87%だった。回帰に置き換える仮説は、この入力と固定閾値では支持されなかった。

E03 でクラス0の予測件数は0件から271件、クラス4は283件から3,615件になった。2段階以上の誤分類率も15.87%から24.35%に上がり、平均絶対段階差は 0.88241 から 0.95131 に増えた。QWK の周辺分布から算出する期待二乗距離が 1.67975 から 2.73238 に増え、実測二乗距離の増加（1.23538 → 1.69659）を上回った。[K027](../../knowledge/K027-qwk-threshold-calibration.md)

E04 は E01 比で +0.01143 だった。有効画像数と `PhotoAmt` は一致していたため、画像の寸法・縦横比・明度の統計に追加情報があったと考えられる。特徴ごとの寄与は未検証。[K026](../../knowledge/K026-image-summary-with-tabular.md)

E01 の Notebook が公開配布テストに出力した CSV はローカルと同じ 3,972 ID・同じ順序だったが、予測クラスは102件で異なった。実行環境はローカルが Python 3.12、Notebook が Python 3.13。差の原因は切り分けていない。

## 上位解法とアブレーション

E02〜E04 の結果を保存した後、以下の本人 writeup を確認した。順位は Kaggle の現在の表示を使った。

- **1位チーム**は複数の特徴セットとモデルを統合し、順位平均を利用した。重複する掲載画像を検出し、推論後のクラス予測にも反映した。本文の2位表記は投稿当初の順位に対応する。[1位チームの概要](https://www.kaggle.com/competitions/petfinder-adoption-prediction/writeups/kaggler-ja-wodori-1st-place-solution-summary)、[主催者による順位変更の発表](https://www.kaggle.com/c/petfinder-adoption-prediction/discussion/125436)
- **12位の corochann** は、本文・画像ラベル・感情分析のエンティティを別々に TF-IDF と SVD で変換し、複数の予測モデルに使った。タイトルの順位表記は13位。[corochann の writeup](https://www.kaggle.com/competitions/petfinder-adoption-prediction/writeups/corochann-13-th-place-solution-summary-0-44091-65-)

E05 は corochann の本文特徴に着想を得た。公式の `Description` に既存の単語1〜2-gram TF-IDF と16次元の SVD を使い、E01 の表特徴に加えた。語彙、IDF、SVD は外側の学習行だけから作った。表入力、目的関数、固定閾値、fold は E01 と共通。QWK は −0.00821 で、今回の本文特徴単独では悪化した。

## 選定と誤差分析

連結保護者グループ単位のペアブートストラップ2,000回（seed 42）で、E01 との差の95%区間の下限が正だったのは E03 と E04。OOF QWK の高い E03 を最終提出前に採用した。区間は同じ OOF の再標本化に基づく。[選定記録](selection.json)

E03 の2段階以上の誤分類は実測クラス0で54.39%と最大だった。画像ありは24.27%（14,652件）、画像なしは27.86%（341件）。保護者の掲載数が1件の群では27.91%、21件以上の群では19.78%だった。各群の値は構成の違いを含む記述統計である。[誤差集計](selection.json)、[実験ログ](experiments.jsonl)
