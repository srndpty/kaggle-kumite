# #021 M5 Forecasting - Accuracy 実験レポート

## データと採点環境

2026-11-23 JST に、公式入力から作った季節ナイーブの CSV で Late Submission の採点完了を確認した。Public WRMSSE は 0.75238、Private は 0.73433。モデル選定には事前に固定した CV のみを使う。

`d_1885` までの売上ゼロ率は68.37%、系列ごとの初売上以降では59.69%。初売上日の中央値は `d_160`。最後の28日間では価格の欠損はなく、価格がある日にも全商品×店舗日の57.41%で売上がゼロだった。価格があるという事実だけでは、在庫や欠品の有無は判断できない。商品×店舗あたりの日平均は土曜1.36個、日曜1.34個、水曜0.98個だった。

同じ締切で直近28日の売上金額は約367万ドル。階層内で最大の系列が占める金額の比率は州43.38%、カテゴリ56.97%、商品×店舗0.40%。この重みによって、同一階層内でも売上金額の大きい系列の誤差がスコアに強く反映される。

## 検証と指標

`d_1829`、`d_1857`、`d_1885` の直後を28日ずつ採点した。学習例の予測窓は外側の締切までに完結させた。合成データで過去の売上特徴と尺度・重みの締切、重みゼロの処理、WRMSSE の手計算を確認した。

`d_1941` 締切で計算した42,840系列の重みを公開参照重みと照合し、最大絶対差は 9.32 × 10⁻¹⁰ だった。ダミー提出のローカル Public は 0.75242074 で、Kaggle 表示との差は約 0.00004。採点側との差の原因は未特定。[主催者の公開資料](https://github.com/Mcompetitions/M5-methods) · [照合に使った参照データのミラー](https://github.com/Nixtla/m5-forecasts/tree/main/datasets)

## 上位解法と再現対象

E00〜E04 の CV を保存した後、上位2件の本人資料を確認した。

- 1位の YeonJun In は店舗、店舗×カテゴリ、店舗×部門ごとに学習した LightGBM を使い、直接予測と再帰予測を等重みで平均した。公開前処理は、対象日から28〜42日前の売上ラグをまとめて作る。[本人論文](https://doi.org/10.1016/j.ijforecast.2021.11.007) · [本人の公開前処理](https://github.com/Mcompetitions/M5-methods/blob/master/Code%20of%20Winning%20Methods/A1/3.%20code/1.%20preprocessing/1.%20preprocessing.py#L377-L415)
- 2位の Matthias Anderer は、上位階層の N-BEATS で得た見通しを基準に、最下層の LightGBM の非対称損失を調整して、予測の合計を整合させた。[本人論文](https://arxiv.org/abs/2103.08250)

E05 では1位の固定起点で利用できる最初の生売上ラグ群28〜42日を E01 に加える。元の解法は販売開始前の行を除いてラグを作る。ここでは E01 と学習行をそろえ、配布された日次行をそのまま使う。モデルは単一の全系列共通回帰とし、E01 と同じ学習起点・系列割り当てで比較する。

E05 の平均 WRMSSE は E01-r2 比 +0.00142。3窓のうち改善は最後の1窓で、今回のラグ群単独では平均の改善を確認できなかった。

## 最終評価と誤差分析

選定記録を固定してから `d_1913` と `d_1941` を締切とする E02 を学習した。提出用 run は `final-v1`。60,980行・28日分の予測をサンプルと同じ ID 順に並べ、形状・重複・有限性・非負性を確認してから提出した。

2026-11-23 JST に Kaggle の最終採点が完了した。

| 提出 | 3窓平均 CV | Kaggle Public | Kaggle Private |
|---|---:|---:|---:|
| E00 の季節ナイーブ | 0.73735 | 0.75238 | 0.73433 |
| E02 の再学習 `final-v1` | 0.69883 | 0.72569 | 0.61599 |
| 差 | −0.03852 | −0.02669 | −0.11834 |

季節ナイーブに対する改善方向は CV・Public・Private で一致した。Private は CV より改善幅が大きい。ログの `late_score` には Kaggle の Private を記録した。[Kaggle 提出履歴](https://www.kaggle.com/competitions/m5-forecasting-accuracy/submissions)

公開期間のローカル WRMSSE は 0.72573541 で、Kaggle との差は約 0.00005。階層別では全体が 0.62164、商品が 0.84568、商品×店舗が 0.83586 だった。商品×店舗の日次 MAE は予測1〜4週の順に 0.97292、1.06127、1.09364、1.04132。

レビュー後に、実際に提出した CSV の ID・行順を公式サンプルと突き合わせ、Public の行を系列順に戻して再採点した。CSV 読み戻しによる WRMSSE の差は E00 でゼロ、E02 で −8.19 × 10⁻¹¹、予測値の最大絶対差はそれぞれゼロと 3.81 × 10⁻⁶ だった。観測された Kaggle との差に比べて十分小さく、残差の原因は未特定。[照合コード](src/verify_metric.py)
