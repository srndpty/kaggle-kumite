# #023 ASHRAE — Great Energy Predictor III 振り返り

## 外部評価の確認

公式サンプルの ID と列順を保持した定数 0 のファイルを提出した。Kaggle の採点結果は Public RMSLE 4.699、Private RMSLE 4.406（提出 ID 58880404）。

## 検証条件

2016年末の28日窓3つを使い、それぞれ窓より前の計測値で学習する。主指標は3窓を結合した RMSLE。実際のテスト期間は翌年以降なので、検証窓で評価できる期間と季節には限りがある。

建物 ID と気象のサイト・時刻キーは右側の一意性を検査した。気象の欠測は残し、時刻補正に使う気温観測は各学習期間に限った。公式配布の入力と検証分割のハッシュは実験ログに記録する。

## 自力実験

| run | 10月9日〜 | 11月6日〜 | 12月4日〜 | OOF RMSLE |
|---|---:|---:|---:|---:|
| E00 | 1.294733 | 1.003444 | 0.863658 | 1.069567483 |
| E01 | 1.227237 | 0.883330 | 0.847977 | 1.001460254 |
| E02 | 1.227237 | 0.883330 | 0.847977 | 1.001460238 |
| E03 | 1.224654 | 0.921340 | 0.846384 | 1.011250555 |

E01 の気象値は全3窓で改善した。メーター別では冷水 −0.14291、蒸気 −0.16003、温水 −0.09902、電力 +0.03759。全体改善と電力の悪化が同時に起きた。

E02 の欠測フラグ追加は全体差が約 −0.000000017。降水深が全欠測のサイト1でもスコア差はなかった。サイト別で差が出たのはサイト4（約 −0.00000153）だった。

E03 の時刻補正は全体で +0.009790。16サイトのうち11サイトで改善したが、サイト0は +0.25323、11月6日からの窓は +0.03801 だった。気温ピークから推定した時刻をカレンダーに適用する手法であり、気象と計測の結合時刻を補正する実験は未検証。

## 上位解法の追試

1位チームは気温ラグや平滑化を使い、2位チームは基本特徴を使うサイト×メーター別のアンサンブルを重視した。 [1位チーム本人の writeup](https://www.kaggle.com/competitions/ashrae-energy-prediction/writeups/isamu-matt-1st-place-solution-team-isamu-matt) · [2位チーム本人の writeup](https://www.kaggle.com/competitions/ashrae-energy-prediction/writeups/cha0s-2nd-place-solution)

E04 では最良の自力実験 E02 に、同一サイトの24時間前の気温だけを追加した。3窓の RMSLE は 1.229793、0.885713、0.846883。全体は 1.002898 で E02 から +0.001437。冷水・蒸気は小幅に改善し、電力と温水は悪化した。追試は気温ラグ1列の効果を測ったもので、複数ラグや平滑化、サイト別のモデル学習は未検証。

## 最終モデルの選定

CV の実測最小値により E02 を選定した。E01 との差は約 0.000000017 で、欠測フラグの実質的な優位を示せる差ではない。

## 誤差分析

選定した E02 の RMSLE は10月9日からの窓が 1.227237 で最も高く、11月6日からは 0.883330、12月4日からは 0.847977 だった。最初の窓の平均対数誤差は −0.07863 で過小予測側だった。サイト7は RMSLE 1.71848、サイト14は 1.63760。サイト14 は576,433行あり、検証全体の二乗対数誤差の 32.73% を占めた。メーター別の RMSLE は電力 0.60723、冷水 1.33922、蒸気 1.36255、温水 1.59019。

## 最終外部評価

全20,216,100学習行で再学習した F00 を提出した。41,697,600件の予測は有限・非負で、公式サンプルと ID 順が一致した。Kaggle 提出 ID は 58882246。Public RMSLE 1.365、Private RMSLE 1.442 で、定数予測の 4.699、4.406 を下回った。

Private RMSLE は選定に使った E02 の OOF 1.001460 より約0.441高かった。CV は2016年末の短期窓でスコア対象の全行を使う。外部評価は翌年以降の公式テスト期間で、Kaggle が指定した行が採点対象になる。年度、季節、採点対象の違いの寄与は切り分けていない。

## 保存した知見

- 同時刻の気象を追加したとき、冷水・蒸気・温水の改善と電力の悪化が同時に起きた。 [K043](../../knowledge/K043-weather-by-meter.md)
- 欠測をそのまま使える LightGBM では、今回の気象欠測フラグの追加差は実質ゼロだった。 [K030](../../knowledge/K030-missing-value-ablation.md)
