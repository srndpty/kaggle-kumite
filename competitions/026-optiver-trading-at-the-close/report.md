# #026 Optiver - Trading at the Close 振り返り

## 採点疎通と検証設計

Python 3.10 の CPU イメージに固定したダミー Notebook で、公式 API を通じた Late Submission が採点された。定数ゼロの Late Private MAE は 5.6036、取引日順 CV の OOF MAE は 6.02155。

末尾90取引日を30日ずつの連続区間に分け、各区間より前の日だけで学習した。公開サンプルの33,000行では、E00〜E03 の一括特徴量と逐次再生の特徴量が一致した。

## Baseline

E00 の OOF MAE は 5.94366。fold 別の MAE は時系列順に 6.34275、5.62407、5.86415 だった。

## 自力の仮説検証

| Run | 特徴群 | OOF MAE | E00 比 |
|---|---|---:|---:|
| E00 | 現バッチの生の板・オークション入力 | 5.94366 | — |
| E01 | 板スプレッド、板数量比、オークション数量比 | 5.93363 | −0.01003 |
| E02 | 同一銘柄の10秒・60秒差分 | 5.93722 | −0.00644 |
| E03 | 同時刻の他銘柄との中央値差・順位 | 5.94382 | +0.00016 |

E01 と E02 は3区間すべてで E00 の MAE を下げた。E03 はこの組み合わせで改善しなかった。90取引日を単位に復元抽出したペア比較（seed 42、10,000回）で、MAE 差の95%区間は E01 が [−0.01237, −0.00789]、E02 が [−0.00837, −0.00462]、E03 が [−0.00199, +0.00215]。E01 と E02 を組み合わせた効果は未検証。

## 上位解法の再現

引け前の節目を明示する方法を6位解法から取り上げた。E04 は E00 に240、300、420、480秒の到達フラグだけを加える。公開ラベルを使った追加学習とアンサンブルの効果は検証範囲外とした。 [6位解法の本人記事](https://www.kaggle.com/competitions/optiver-trading-at-the-close/discussion/486040)

E04 の保存 OOF は全検証行で E00-r2 と一致し、`oof.npy` の SHA-256 も同じだった。秒位置を直接入力する今回の木モデルでは、この4フラグを加えても検証行の予測値は変わらなかった。特徴量重要度は確認していない。

## OOF のエラー分析

選定候補 E01-r2 の全検証行 MAE は 5.93363。初回 E01 と再実行の OOF 予測は全検証行で一致した。

| 秒位置 | 検証行 | MAE |
|---|---:|---:|
| 0–179秒 | 323,999 | 5.84398 |
| 180–359秒 | 324,000 | 7.03564 |
| 360–540秒 | 342,000 | 4.97454 |

取引日別 MAE の10・50・90パーセンタイルは 5.03464、5.77273、7.20158。最大は `date_id=458` の 9.48446。銘柄別では同じ順に 4.01898、5.38326、8.52670 で、最大は `stock_id=31` の 18.65438 だった。

## 最終選定と export

5候補の保存 OOF を再採点し、E01-r2 を選んだ。選定記録 `outputs/selections/F00.json` とソース・設定を照合した後、ラベルのある全学習行で F00 を学習した。F00 は Kaggle の Notebook ソース上限を超えるため、照合済みの推論コードとモデルを別ファイルに梱包し、読込用 Notebook 側で SHA-256 を検証する構成にした。配布物は `deployment-manifest.json` で export ID とハッシュを結び、内容が違う再生成は拒否する。逐次推論は空でない単一時点の一意なキーだけを受け、同じ時点の再入は拒否する。

2026-11-26 に [F00 の非公開 Notebook v1](https://www.kaggle.com/code/shion5/kumite-optiver-close-f00) を提出し、Late Private MAE **5.5239** を得た。同じ外部評価で定数ゼロの 5.6036 から 0.0797 改善した。CV でも定数ゼロの 6.02155 に対して 5.93363 と改善した。両方のモデルで Late Private MAE が CV より低く、評価期間と F00 の全量再学習が差に与えた影響は未分離。

同日の過去入力だけを使うラグ特徴の検証結果を [知見カード K008](../../knowledge/K008-reproduce-information-cutoff-in-validation.md) に追記した。
