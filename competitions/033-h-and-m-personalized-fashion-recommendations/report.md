# #033 H&M Personalized Fashion Recommendations 振り返り

## 結果

- 選定計画 `selection-p7.json` の5候補を再採点し、E06 を選んだ。OOF MAP@12 は 0.03348（窓別 0.03338 / 0.03309 / 0.03401）。全取引で学習し直した F00 は Late Public 0.02861 / Private **0.02899**。
- 人気上位だけの B00 は OOF 0.00733、Private 0.00703。公式サンプルは Private 0.00286。
- F00 は CV より 0.0045 低く、B00 は 0.0003 低い。人気だけの予測ではほぼ一致するのに、個人化した予測では差が開いた。1位の本人 writeup でも CV 0.0430 に対して LB 0.0362 と低い。テスト週の性質、顧客層の構成の違い、最終学習の違いのどれによるかは切り分けていない。候補以外の提出はしていないので、E04 と E06 の差が外部でも再現するかは未確認。

## 自力の仮説で効いたこと・効かなかったこと

顧客単位の bootstrap（2,000回、seed 42）で、同じ（窓, 顧客）どうしの MAP の差を見た。

| 比較 | 変更 | 差 | 95%区間 |
|---|---|---:|---|
| E00 → E01 | 本人の直近28日の購入 | +0.01714 | [+0.01667, +0.01765] |
| E01 → E02 | 人気の時間減衰 | +0.00012 | [+0.00006, +0.00018] |
| E01 → E03 | 共購入の候補 | +0.00179 | [+0.00168, +0.00190] |
| E03 → E04 | LambdaRank（候補固定） | +0.00467 | [+0.00433, +0.00500] |
| E04 → E05 | 学習週 1 → 4 | −0.00036 | [−0.00059, −0.00011] |

- 最大の改善は再購入。E01 は全 2,601,900 枠のうち 465,077 枠を過去に買った商品に使い、命中の過半（14,924 / 26,222）がそこから出た。
- 共購入（E03）は MAP 横ばいと予想したが改善した。再購入以外の命中が 11,298 → 14,084 に増えた。
- 再ランキング（E04）は、再購入の枠を 470,903 → 351,976 に減らしながら再購入の命中を保ち（15,049 → 14,916）、それ以外の命中を 14,084 → 18,962 に増やした。
- 学習週を増やす E05 は、最初の窓だけ悪化（−0.00137）し、残る2窓はわずかに改善（+0.00013、+0.00024）した。fold 間で向きがそろわず、教師を増やす効果は確認できない。

## 上位解法から学び、再現したこと

| 比較 | 変更 | 差 | 95%区間 |
|---|---|---:|---|
| E04-r2 → E06 | 本人の購入を365日（8位。期間は自分で固定） | +0.00255 | [+0.00225, +0.00286] |
| E04-r2 → E07 | 同じ product_code の候補（8位） | −0.00011 | [−0.00034, +0.00012] |
| E04-r2 → E08 | 候補 100 → 300 件（3位） | −0.00182 | [−0.00209, −0.00152] |
| E04-r2 → E09 | E06・E07・E08 の組み合わせ | +0.00071 | [+0.00037, +0.00103] |

- E06 は候補 Recall を 0.130 / 0.124 / 0.141 から 0.124 / 0.119 / 0.134 に下げたのに MAP を上げた。改善は直近28日に購入のない顧客（全体の47.6%）に集中し、0.01103 → 0.01694。直近28日に購入のある顧客は 0.05634 → 0.05579 とわずかに悪化した。共購入の起点も一緒に伸びるため、再購入候補と共購入候補のどちらの寄与かは切り分けていない。
- E08 は候補 Recall を約2倍（0.233〜0.251）にし、MAP の上限も 0.14〜0.16 から 0.25〜0.27 に上げたが、MAP は下げた。再購入以外の命中は 18,962 → 15,671 に減った。増えた候補は人気101位以下なので、ランキングの特徴が足りない、または候補が増えた教師の構成と固定ラウンド数の組が合わない可能性がある。どちらかは切り分けていない。3位は候補源ごとの順位を特徴に入れると候補数の拡大が効くと述べている。E08 にも候補源の順位は入れているが、他の特徴や間引きは異なる。
- E09 は各単独より高いという予想に反し、E06 に −0.00184 及ばなかった。候補拡大の悪化が残ったとみられる。

## 上位解法との差分（試さなかった着眼点）

- 行列分解や word2vec の類似度、負例の間引き、属性別の人気、顧客ベースの協調フィルタ、複数モデルの平均。
- 1位の公開値と比べると、E04 の候補100件の命中数は 73〜77%。候補の質を人気や再購入以外の手掛かりで上げる余地がある。

## 既知の問題・未検証の事項

- 初めて売れた商品（購入ペアの 2.5〜5.4%）は候補に入らない。
- 年齢は取得時点のスナップショットで、窓ごとの値との差は確認できない。
- E08 の悪化の原因、学習週・候補数・ラウンド数の相互作用。
- CV と Private の差の原因。
