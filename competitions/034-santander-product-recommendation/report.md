# #034 Santander Product Recommendation 振り返り

## 比較結果

すべて同じ3月・4月の拡張窓と、同じ保有済み商品の除外を使った。対象は正解の確定した 1,842,484 顧客月。3月・4月の内訳と除外条件は [README](README.md) に記録した。

| Run | 順位付け | 3月 MAP@7 | 4月 MAP@7 | OOF MAP@7 |
|---|---|---:|---:|---:|
| E01 | 全期間の商品別取得率 | 0.02023670 | 0.01871045 | 0.01947178 |
| E02 | 直近3か月の商品別取得率 | 0.02023336 | 0.01848801 | 0.01935863 |
| E03 | 保有商品数3群別の取得率 | 0.02108394 | 0.01959745 | 0.02033894 |
| E04 | 前月の保有状態を使う商品別 L2 ロジスティック回帰 | 0.02435018 | 0.02289962 | 0.02362319 |
| E05 | 前年同月の重みを2倍にした取得率 | 0.02023499 | 0.01871045 | 0.01947093 |

保有済み除外を全 run に施した上で、保有商品の情報を順位付けにも使うと改善した。保有数だけを条件にした E03 は E01 比 +0.00086716、商品ごとの保有状態を使う E04 は +0.00415141。E02 と E05 では事前に予想した改善が得られなかった。E05 で試したのは取得率の集計時に前年同月の件数を増やす方法で、上位解法のモデル混合や6月固有の季節性は未検証。

## 最終モデルの固定

CV 最上位の E04 を採用した。顧客単位で1,000回再標本化した E04 と E01 の MAP@7 差の95%区間は +0.00407610〜+0.00423055。3月と4月に同じ顧客が出た場合は同じ再標本に入れた。5月のホールドアウト評価前に採用モデルと選定指標を保存した。 [選定記録](selection.json)

## 5月ホールドアウト

固定モデル E06 は、5月の 931,453 行のうち過去と当月の保有が確認できる 926,663 行で MAP@7 **0.02447**。評価対象の 96.99% は新規取得ゼロだった。

| 前月の保有商品数 | 評価行 | MAP@7 |
|---|---:|---:|
| 0 | 231,692 | 0.008003 |
| 1 | 452,739 | 0.015508 |
| 2以上 | 242,232 | 0.056958 |

取りこぼしが最も多かったのは `ind_ctma_fin_ult1` で、512 件中 505 件が上位7件に入らなかった。次いで `ind_ctop_fin_ult1` が 226 件中 168 件、`ind_reca_fin_ult1` が 279 件中 130 件だった。保有数別 MAP@7 には、群ごとの新規取得率の違いも含まれる。

## 6月の外部評価

5月までの取得情報で再学習した E06 を、2026年11月22日（日本時間）に Late Submission で採点した。

| Run | Public MAP@7 | Private MAP@7 |
|---|---:|---:|
| E00 採点確認 | 0.00374 | 0.00379 |
| E01 Baseline | 0.02365 | 0.02388 |

最終モデルの Baseline 比は Public −0.00005、Private +0.00003。3月・4月の CV で見られた改善幅は6月の外部評価では再現しなかった。予測月と評価対象が内部・外部で異なるため、差の原因は未特定。モデル選定は3月・4月の CV で完了し、5月および Kaggle のスコアは固定後の確認に用いた。

## レビュー後の監査

初回の `monthly-v1` では各 CV run で、CV 採点とは別に5月までの履歴から6月の予測を生成していた。E04 と E06 の提出 CSV および `test.npy` の SHA256 はそれぞれ同一だった。3月・4月の採点と、選定固定後の5月採点には、各予測月以降のラベルは使っていない。レビュー後は `monthly-v2` で CV と6月の推論を分離した。既存の評価配列から E01〜E05 の MAP@7 を再計算してログと照合し、E04 の選定に使ったハッシュを追記した。

保存済みの予測で、AP@7 の加点を的中した商品に割り当て、E04 と E01 の差を商品別に分解した。取得率は各月の評価対象のうち、前月に当該商品を保有していない顧客を分母にした。CV の改善幅の約64%は上位3商品に由来した。6月は商品別の正解が得られないため、外部評価との差の原因は特定できていない。

| 商品 | CV の MAP@7 差への寄与 | 3月の取得率 | 4月の取得率 | 5月の取得率 |
|---|---:|---:|---:|---:|
| `ind_tjcr_fin_ult1` | +0.00133378 | 0.4975% | 0.4611% | 0.4763% |
| `ind_nom_pens_ult1` | +0.00067128 | 0.5796% | 0.5070% | 0.6293% |
| `ind_recibo_ult1` | +0.00066350 | 1.2483% | 1.2060% | 1.2471% |
| `ind_cco_fin_ult1` | −0.00017028 | 1.2674% | 1.1125% | 1.0563% |

今後の実験では、学習機会がゼロの群には全体の商品取得率を用い、全体でも機会がゼロの商品は推定不能として扱う。商品別ロジスティック回帰の監査には、学習機会数・陽性数・保有パターン数・反復回数・単一クラスへの対応および収束警告を残す。今回の実測値は当初の平滑化と学習設定による結果。
