## 自力の仮説で効いたこと・効かなかったこと

単語の類似度を等重みで加えた E01 では候補 Recall がわずかに改善し、5 fold すべてで F1 が低下した。画像候補を加えた E02 では候補 Recall が +0.03023、F1 上限が +0.01414。タイトルの類似度だけで採用を決めると追加候補は最終予測を変えなかった。E03 は E02 と同じ3,193,074組を、タイトル・画像 cosine と画像ハッシュ一致で再判定し、平均 F1 を +0.07892 改善した。

## 上位解法の再現

E04 は2位解法の双方向フィルタを E03 の採用済みペアだけに適用した。閾値と候補は共通で、平均 F1 の差は +0.00215。分割の連結成分単位で同じ行を再標本化した95%区間は +0.00191〜+0.00239。5 fold すべてで改善した。除外した947組の片方向ペアのうち、831組は誤一致、116組は正解だった。 [2位の writeup](https://www.kaggle.com/competitions/shopee-product-matching/writeups/lyaka-tkm-2nd-place-solution-matching-prediction-b)

## エラー分析

- 6件以上の商品グループの E04 F1 は 0.79248。1出品あたり正解0.510件が候補から漏れ、3.836件が候補に入ってから棄却された。候補生成に加えて採用判定にも改善余地がある。
- E00 の候補に含まれる正解との最大タイトル cosine が 0.5 以下の出品では、F1 が E00 の 0.61514 から E04 の 0.76598 に上がった。E00 の候補に正解が1件もなかった624件では 0.54951 → 0.69008 だった。
- 同じ画像 ID を他の出品と共有する行では E04 F1 が 0.88433、共有しない行は 0.83500。共有ありでも1出品あたり誤一致は1.107件あり、画像の共有だけで商品一致を決めると誤りが生じる。

候補 Recall と F1 上限の伸びが、固定候補を再スコアリングしたときの改善につながった。検索対象の規模が変わったときに同じ閾値が通用するかは、別の規模での評価が必要になる。 [K038](../../knowledge/K038-retrieval-vs-reranking.md)
