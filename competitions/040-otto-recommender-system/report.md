## 上位解法

- 2位の本人 writeup は、行動種別や経過時間で商品ペアを重み付けした複数の共起行列を使う。 [ONODERA の writeup](https://www.kaggle.com/competitions/otto-recommender-system/writeups/sos3-2nd-place-solution-onodera-part)
- 5位の本人 writeup は、共起行列の重み、商品の最近性、頻度などを Optuna で調整して候補を選ぶ。 [Nikhil Mishra の writeup](https://www.kaggle.com/competitions/otto-recommender-system/writeups/nikhilmishra-6th-place-solution)
- 12位の本人 writeup は、共起による候補に SRGNN の候補を足し、予測時点から候補商品の前回イベントまでの時間差も順位付けの特徴量に使う。E04 はこの着眼点を経過秒1列に絞り、E02 と同じ候補と教師で比べる。 [buumoo の writeup](https://www.kaggle.com/competitions/otto-recommender-system/writeups/buumoo-12th-place-solution)

## 入力セッション長別の誤り

`E02-final` と `B00-final` の加重 Recall@20 の差は +0.01032（95%区間 [0.00991, 0.01072]）。

| 入力イベント数 | 加重 Recall@20 の差 | 注文 Recall@20 の変化 |
|---|---:|---:|
| 1 | −0.00071 | 0.35972 → 0.35927 |
| 2〜4 | −0.00047 | 0.55746 → 0.55701 |
| 5以上 | +0.01621 | 0.62231 → 0.64904 |

改善は5イベント以上の注文に集中した。4イベント以下の入力では、3行動すべてで正解ヒット数がわずかに減った。
入力長1件・2〜4件・5件以上の構成比は CV で 45.38% / 33.29% / 21.33%、公式テストで
44.87% / 33.27% / 21.86% だった。

## 既知の問題・未検証の事項

検証では学習セッションを ID で決まる位置で疑似切断する。公式テストの切断規則は公表されている範囲でしか確認できず、
入力長の構成比は CV と公式テストで近かった。末尾イベントの構成や正解の再出現率が CV と外部スコアの差に占める割合は未検証。
