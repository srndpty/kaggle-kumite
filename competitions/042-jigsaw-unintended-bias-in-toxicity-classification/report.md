Notebook 経由の E00 は公式 Private 0.50000 だった。Late Submission 履歴には Public 0.00000 と表示された。属性注釈の欠損率は 77.55% で、指標上の非所属側に含まれる。集団の定義はコメント中の言及に基づく。 [Kaggle 公式の評価仕様](https://www.kaggle.com/c/jigsaw-unintended-bias-in-toxicity-classification)

## 上位解法とアブレーション

P4 の3件が揃ってから、各チームの一次資料を確認した。

- 1位 ODS AI Toxiciology は、全体と3種類の部分集団に対する BCE を組み合わせ、誤差が大きい集団を重視した。最後に複数の事前学習言語モデルの順位を平均した。 [1位チームの writeup](https://www.kaggle.com/competitions/jigsaw-unintended-bias-in-toxicity-classification/writeups/ods-ai-toxiciology-1st-place-solution)
- 3位 F.H.S.D.Y. は、LSTM 系で注釈者数を損失の重みに使い、BERT・GPT2 系では本文の先頭と末尾のトークンを残した。 [3位チームの writeup](https://www.kaggle.com/competitions/jigsaw-unintended-bias-in-toxicity-classification/writeups/f-h-s-d-y-3rd-place-solution) · [公開コード](https://github.com/sakami0000/kaggle_jigsaw)
- 4位 COMBAT WOMBAT は、有害性と補助タスクに連続ラベルを使い、属性ラベルの欠損行は属性を学習する損失の重みをゼロにした。 [4位チームの公開コードと解説](https://github.com/iezepov/combat-wombat-bias-in-toxicity)

E05 では4位の連続ラベルだけを E01 に導入した。投票比率が `t` の行を、陽性に重み `t`、陰性に重み `1 − t` の二値例として扱うと、元の1行と同じ重みで連続ラベルの二値交差エントロピーを計算できる。比較では TF-IDF、モデル設定、評価時の閾値を固定した。

E05 の合成 OOF は **0.59168**、Subgroup は **0.61939** で、どちらも E01 を下回った。各 fold の最適化は5反復で終了し、OOF 予測の10〜90パーセンタイルは 0.09969〜0.10523 に集中した。E01 の範囲は 0.00744〜0.17052。連続ラベルでの収束許容値や最適化手法の再調整は未検証。

## 最終選定と外部評価

OOF が最大の E03-r2 と E01 の差は +0.01954。本文グループ単位のペアブートストラップ（399回、seed 42）の95%区間は [+0.01871, +0.02025]。区間の下限がゼロを上回ったため、2026-11-22 12:50:25 JST に E03-r2 を固定してから外部評価を行った。この区間は固定した OOF の再標本化に基づく。

Public の97,320件は別の本文集合で、同じ分割で再学習した3 fold の平均予測を採点した。BPSN のべき平均は +0.04321、BNSP は +0.00116 で、いずれも OOF と同方向だった。

配布版 `test.csv` は公式 Private の97,320件と ID が一致した。3 fold の平均予測で、Private の BPSN のべき平均は +0.04673、BNSP は +0.00426。低かった black の BPSN は OOF で 0.66659 → 0.73898、Private で 0.66480 → 0.73513。Private の対象は、属性言及ありの非有害515件と、非所属側の有害7,531件だった。
