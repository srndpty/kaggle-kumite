# #046 Quora Insincere Questions Classification 振り返り

## 結果

陽性率 6.19% の質問分類で、同じ確率予測に対する閾値の効果を測った。E00 の固定閾値 0.5 では OOF F1 が 0.50922、Late Public が 0.52431、Late Private が 0.52626 だった。

最終モデルは OOF F1 が最高の E02（0.62319）を選んだ。最終 Notebook でも学習データを文面グループ単位で分け、同じ単一モデルで保留側と提出側の確率を出す。[選定記録](selection.json)

Late Public F1 は **0.62054**、Late Private F1 は **0.63519**。E00 比で OOF は +0.11397（文面グループ単位のペア・ブートストラップ 95% 区間 [+0.11104, +0.11703]）、Public は +0.09623、Private は +0.10893 だった。公式採点の差は閾値調整と文字特徴を合わせた結果。Notebook では閾値 0.26000331 を使い、375,806 行のうち 27,032 行を陽性と判定した。出力の列・ID 順・件数・二値を公式サンプルと照合した。[最終採点 Notebook 版 1](https://www.kaggle.com/code/shion5/kumite-quora-insincere-final-e02)

## 自力の仮説で効いたこと・効かなかったこと

E01 は外側学習行の一部だけで閾値を選んだ。閾値は 0.217〜0.231 で、同じ OOF 確率からの F1 は 0.60346 に上昇した。文面グループ単位のペア・ブートストラップ 95% 区間は差 [+0.09135, +0.09728]。fold 別 Recall は 0.396〜0.409 から 0.660〜0.681 へ上がり、Precision は 0.691〜0.695 から 0.545〜0.554 へ下がった。

E02 は語内文字 3〜5-gram を加え、OOF F1 0.62319（E01 比 +0.01973、95% 区間 [+0.01813, +0.02132]）。各 fold で AP も上がった。短い質問（45 文字以下）では誤検出が 8,142 → 6,643 件に減り、見逃しは 5,006 → 5,155 件に増えた。長い質問（85 文字超）では見逃しが 11,838 → 10,808 件に減った。単語語彙のカバー率が 100% の行でも誤検出は 38,324 → 34,364 件に減った。カバー率 50% 以下では陽性が 25 件で、見逃しは両 run ともに 20 件だった。

E03 のクラス重み付けは OOF F1 0.60595（E01 比 +0.00249、95% 区間 [+0.00104, +0.00398]）。調整後の閾値は 0.809〜0.823 まで上がり、判定率は E01 と近かった。

## 上位解法から学び、再現したこと

- Private 1 位 The Zoo は BiLSTM、幅 1 の Conv1D、最大プーリングと統計特徴を組み合わせた。埋め込みの語彙は大小文字を保持し、分類閾値の安定化に予測順位を使った。E04 は大小文字を保持する着眼点を E01 の単語 TF-IDF に移した。[本人の writeup](https://www.kaggle.com/competitions/quora-insincere-questions-classification/writeups/the-zoo-1st-place-solution)
- Private 3 位 Guanshuo Xu は BiLSTM と BiGRU を直列に置き、両層の最大プーリングを結合した。埋め込みの組み合わせと学習途中の重みを変えて予測を平均し、固定閾値 0.35 で判定した。[本人の公開 Notebook](https://www.kaggle.com/code/wowfattie/3rd-place)

E04 の OOF F1 は 0.60655（E01 比 +0.00310、95% 区間 [+0.00184, +0.00428]）。85 文字超では見逃しが 11,838 → 11,280 件に減り、誤検出が 19,125 → 20,004 件に増えた。文字特徴を含む E02 と大小文字保持を組み合わせる比較は未検証。

## 上位解法との差分（試さなかった着眼点）

今回の比較は CPU の単一ロジスティック回帰と公式 CSV に絞った。事前学習埋め込み、系列モデル、予測順位、チェックポイント平均は未検証。

## 既知の問題・未検証の事項

文字特徴で改善する要因を綴り変形だけに帰属できるかは未検証。公式テストと CV には学習行数の差（約 87 万行と約 58 万行）もあるため、F1 差には評価集合と学習量の両方が関わりうる。
