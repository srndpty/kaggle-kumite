## 上位解法の追試と誤差分析

学習ラベルが5種類以下の列で、予測の順位を経験分位点へ写像した E04-review は対照に比べ OOF が +0.01293。質問群単位のペア bootstrap 400回による95%区間は [+0.00280, +0.02309]。5 fold 中4 fold で改善した。同じ OOF を再標本化した区間であり、学習や分割の再実行に伴う変動は含まない。

改善は `question_type_spelling` の 0.07229 → 0.54448 に集中した。この1項目を除いた29項目平均では後処理の効果は約 −0.00290。指示を求める質問（0.69103）は比較的予測しやすく、質問になっていない投稿（0.01948）や回答のもっともらしさ（0.07735）は弱かった。

本文長の三分位（393字、803字）で選定モデルの OOF を再集計すると、短文 0.34140、中間 0.33163、長文 0.30332。主要サイト別では Stack Overflow 0.19414、Server Fault 0.27637。サイトや文長でラベル分布も変わるため、群別順位相関の差は誤差の傾向として扱う。

## 外部評価

P0 ダミーは Public 0.00586、Private 0.00372 で公式採点を確認した。B00 の記録は内部 CV のみ。CV 選定済み E04-review の F00（Notebook 第1版、提出 58942189）は、公開テスト上では列・ID・値域検査を通過した。非公開テストの採点では Kaggle API が形式エラーを返し、Public・Private とも空欄だった。公開テストでは、分位点写像後の綴り項目は476行中475行が同じ値になった。採点部分集合で定数になった可能性はあるが、API のエラーから原因は特定できない。

形式エラー後、P4 の勝者を外部評価用の候補として事前登録した。E01-external の F01（Notebook 第2版、提出 58942363）は Public 0.30035、Private 0.28560。自身の OOF 0.32460 に対してそれぞれ −0.02425、−0.03900 だった。外部採点まで成立したモデルは E01-external として確定した。CV で選んだ E04-review はスコア未取得のため、後処理の効果は外部で比較できない。

選定記録、Notebook 版、提出 ID とハッシュは [採点証跡](submission-evidence.json) に記録した。再利用条件は [K054](../../knowledge/K054-field-specific-text-features.md) と [K055](../../knowledge/K055-empirical-quantile-rank-ties.md) に記録した。
