# #048 Tweet Sentiment Extraction 振り返り

**語内の文字 3〜5-gram を追加した E02 を採用した。** OOF Jaccard は 0.64348、E01 から +0.00707。固定分割版の Late Submission は Public 0.64928、Private 0.64991。

## 検証設計

27,480行を正規化した本文でグループ化し、感情を層化した5分割（seed 42）で検証した。語彙とモデルは各 fold の学習側だけで作った。正解の出現位置が複数ある113行は位置教師から外し、採点には残した。正解位置を一意に特定できても、空白区切りの単語境界で完全一致を作れない行が2,922行あった。モデルは空白区切りの区間を選び、文字オフセットで元の本文から句読点や空白を保ったまま切り出す。

## 上位解法とアブレーション

- 1位の Dark of the Moon は Transformer で開始・終了境界を推定した。メンバーの一部は Jaccard に基づくソフトラベルを学習に使い、チームは文字レベルのモデルで複数モデルを組み合わせた。 [1位チームメンバーの実装と解説](https://github.com/heartkilla/kaggle_tweet)
- 60位の DimitreOliveira は、RoBERTa に開始・終了位置と抽出区間内のマスクを同時に学習させた。推論では fold の境界ロジットを足し合わせ、原文にない語を除いた。 [60位の本人 writeup](https://www.kaggle.com/competitions/tweet-sentiment-extraction/writeups/dimitreoliveira-60th-place-silver-medal-solution-g)

E05 は1位解法の「区間の評価に Jaccard を反映する」という着眼点を推論に移した。E01 と同じ包含確率を使い、各語の正解集合への包含確率を本文中での最大値で近似した。候補区間の単語集合について、期待交差サイズを期待和集合サイズで割った値が最大の区間を選んだ。この比は Jaccard の近似値であり、語同士の共起はモデル化していない。

## 実験結果

|---|---|---:|---:|---:|---:|

| E01 | 語と感情で区間を推定 | 0.63641 | — | 0.63778 | 0.64024 |
| E02 | 語内の文字 3〜5-gram | **0.64348** | **+0.00707** | **0.64928** | **0.64991** |
| E03 | 直前・直後の語 | 0.63618 | −0.00023 | — | — |
| E04 | neutral は全文 | 0.63642 | +0.000004 | — | — |
| E05 | Jaccard を近似する区間選択 | 0.61184 | −0.02457 | — | — |

E02 は negative で +0.01627、positive で +0.00798。英字が3回以上連続する2,157行では +0.02650 だった。この部分集団には表記変形以外の語も含まれる。E03 は否定語または強調語の簡易パターンに該当する7,177行で +0.00608 だったが、全体ではわずかに悪化した。E04 の neutral は +0.00001 だった。E01 が neutral の大半ですでに全文を選ぶため、例外規則の追加効果は小さかった。E05 は positive で −0.06544、negative で −0.01459 だった。予測区間の平均語数は positive で 1.09 から 8.67、negative で 1.10 から 11.08 に増えた。両群とも正解の中央値は2語で、近似式の導入で予測が大幅に長くなった。

## 採用と誤り分析

本文グループ単位のペアブートストラップ2,000回で、E02 − E01 の OOF Jaccard 差の95%区間は [0.00502, 0.00898]。同じ OOF を再標本化した区間であり、モデル選択をやり直した場合の不確実性は含まない。最終提出の前に採用 run と OOF のハッシュを保存した。 [選定記録](selection.json)

## 外部評価の再現性

初回の E01／E02 Notebook は Kaggle 上で分割を作成した。ローカルの scikit-learn 1.9.1 と Kaggle の 1.6.1 で同じ seed から異なる分割が得られたため、両方を Notebook v2 で再提出した。初回スコアは E01 が Public 0.63779・Private 0.63979、E02 が Public 0.64912・Private 0.64986。結果表には v2 を記載する。v2 はローカルで生成した fold 割り当てを受け取り、学習 ID の並びを検査する。実行ログの fold ハッシュが両方ともローカルと一致した。公開テスト入力 3,534行の抽出結果を照合すると、E02 は全行一致、E01 は1行で異なった。固定分割版の E02 は E01 に対して Public +0.01150、Private +0.00967 で、OOF と同じ改善方向だった。実験ログの `late_score` には Private を記録した。

実験の再実行手順とハッシュは各ファイルに記録した。 [README](README.md) · [実験ログ](experiments.jsonl) · [知見カード K016](../../knowledge/K016-character-features-in-text.md)

## レビュー後の監査

公式 CSV と固定分割のハッシュを照合し、6件の保存済み予測を再採点した。行ごとのスコアと全行平均が記録と一致し、E02 が再度選定された。提出前の選定記録はその時点の証跡として保存している。

ローカルのアップロード用 Notebook と Kaggle から取得したコードセルが一致した。セルのハッシュは、コードセルのソース文字列を順番どおりに並べた配列を、UTF-8 の空白なし JSON に直列化して算出した。v2 の Notebook 出力 CSV とローカル CSV はバイト単位のハッシュが異なるが、CSV として読み込んだ3,534行は一致した。Kaggle の採点結果は Notebook v2 の提出記録で照合した。CSV ハッシュの対象はダウンロードできる Notebook 出力で、非公開テスト再実行時の出力は取得できない。 [提出監査記録](submission-audit.json)
