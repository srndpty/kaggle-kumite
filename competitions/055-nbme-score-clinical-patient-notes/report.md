## 評価の途中経過

公式データの1,000ノート、14,300項目ペアをノート単位で5分割した。全件空欄のダミーは Kaggle で Public・Private ともに 0.00000 だった。

| run | 全 OOF の文字単位 micro-F1 |
|---|---:|
| B00 | 0.76145 |
| E01 | 0.70386 |

| E03 | 0.80106 |

## 空白の連結

E03 は B00 のトークン確率をそのまま使い、陽性区間の間の空白を補った。全5 fold・全10ケースで micro-F1 が上がった。全 OOF で偽陰性文字が 56,061 から 41,453 に減り、偽陽性文字は 29,281 から 33,458 に増えた。複数の予測区間に分断されていた正解区間は 7,185 から 520 に減った。

E03 のケース別 micro-F1 はケース 5 が 0.71542、ケース 3 が 0.85018 だった。正解ありで予測が空の 388 ペアと、正解なしで予測がある 615 ペアは B00 と同数だった。

## 上位解法から試した期間単位のフィルター

3位の着眼点から、2か月を問う項目について、明示的に「2週」または「年」に重なる予測区間を除外した。E04 と B00-r2 の保存区間は全件一致し、OOF は両方 0.76102 だった。このモデルでこの規則が適用される予測はなかった。 [3位チームの writeup](https://www.kaggle.com/competitions/nbme-score-clinical-patient-notes/writeups/lakecity-3rd-place-solution-meta-pseudo-labels-kno)

## 最終選定とエラー分析

全候補の保存 OOF を再採点し、E03-r2 を OOF micro-F1 0.80082 で選定した。最初の F00 では Kaggle 側の ZIP 自動展開と読み込み先が一致しなかった。配置だけを修正し、同じ保存 OOF を依存成果物として再検証した。再選定された E03-r2-pkg の OOF も 0.80082 で、F01 の構成を決める根拠にした。E02 の差は初回 −0.00538、再実行 +0.00166 と向きが変わった。固定 seed でもスコアが変動し、この差の再現性は確認できなかった。 [選定記録](selection.json)

選定 run ではケース 5 が最も低い 0.71400、ケース 3 が最も高い 0.84844 だった。正解ありの空予測は 404 ペア、正解なしの誤検出は 603 ペア。予測がある行で、単一の重なり区間の境界が正解と違った区間は 2,647 件、複数の予測区間に分断された正解区間は 544 件だった。
