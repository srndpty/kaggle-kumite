# #059 Cassava Leaf Disease Classification 振り返り

## 評価環境と分割

クラス 0 の定数予測で Late Submission の採点経路を確認した。Public 0.0481、Private 0.0507。ローカル CV の多数クラス定数 E00 は OOF Accuracy 0.61495。外部採点に出したクラス 0 と CV で選ばれた多数クラス 3 は別の予測なので、これらの値から CV と外部評価の差は推定できない。

全 21,397 件を 3 fold で検証する。dHash で検出した近重複は同じ fold にまとめた。撮影元 ID がないため、近重複として見つからなかった同一個体や撮影環境をまとめた評価は未検証。

## 学習モデルの比較

E01 の OOF Accuracy は 0.77296。クラス 0〜4 の再現率は順に 45.6%、66.0%、58.3%、88.2%、62.1%。最少クラスの 0 は 1,087 件中 350 件をクラス 4 と誤分類した。事前仮説と再現コマンドは [README](README.md) を参照。

E02 は Accuracy 0.79679（E01 比 +0.02383、近重複グループ単位のペア bootstrap 95% 区間 +0.01823〜+0.02893）。クラス 0〜4 の再現率は 52.9%、61.8%、49.3%、92.7%、67.5%。正答は全体で 510 件増え、そのうち最多クラス 3 の正答増は 598 件だった。頻度の小さいクラスのうち 0 と 4 は改善し、1 と 2 は低下した。

E03 の学習時水平反転は Accuracy 0.80175（E01 比 +0.02879、95% 区間 +0.02369〜+0.03407）。クラス 4 の再現率は 62.1% から 74.1% に増え、クラス 0 は 45.6% から 45.9% だった。

E04 の 320 px 入力は Accuracy 0.81881（E01 比 +0.04585、95% 区間 +0.04038〜+0.05131）。クラス 2 の再現率は 58.3% から 67.8% に増えた。一方、クラス 1 の再現率は 66.0% から 61.9% に低下した。解像度による改善の原因を画像ごとに特定する検証は未実施。

E05 は E01 の重みを固定し、元画像と水平反転画像の予測確率を平均した。Accuracy は 0.79156（E01 比 +0.01860、95% 区間 +0.01505〜+0.02229）。左右反転は学習時と推論時の単独比較でともに改善した。

## モデル選定と誤り

全候補の OOF を再採点し、Accuracy が最大だった E04 を選定した。E04 の混同行列は次のとおり。

| 正解＼予測 | 0 | 1 | 2 | 3 | 4 | 再現率 |
|---|---:|---:|---:|---:|---:|---:|
| 0 | 506 | 87 | 33 | 76 | 385 | 46.6% |
| 1 | 151 | 1,355 | 110 | 193 | 380 | 61.9% |
| 2 | 49 | 67 | 1,617 | 370 | 283 | 67.8% |
| 3 | 77 | 130 | 444 | 12,205 | 302 | 92.8% |
| 4 | 243 | 108 | 147 | 242 | 1,837 | 71.3% |

クラス 0（細菌性葉枯病）の正解 1,087 件中 385 件をクラス 4（健全）と予測した。E04 でもこの誤りが残り、クラス 0 の再現率改善は E01 比 +0.9 ポイントだった。

## 外部評価

公開サンプルでは、Kaggle 出力とローカル推論の画像 ID・ラベルが一致した。

| run | OOF Accuracy | Public | Private | Notebook |
|---|---:|---:|---:|---|
| E01 | 0.77296 | 0.8326 | 0.8227 | CPU v1 |
| E04 | 0.81881 | 0.8534 | 0.8528 | GPU v1 |

E01 は CPU v1 の採点待ちの間に同じ重みで GPU v2 を登録した。CPU v1 が先に採点されたため、GPU v2 の Late Submission は見送った。

E04 の改善は OOF +0.04585、Public +0.0208、Private +0.0301 で、3 指標で方向が一致した。外部採点では 3 fold モデルの確率を平均し、OOF では各画像を 1 モデルで予測した。改善幅の違いには、この予測方法の差と評価画像の違いが含まれる。実験ログの `late_score` は Private Accuracy。 [Kaggle 提出履歴](https://www.kaggle.com/competitions/cassava-leaf-disease-classification/submissions)
