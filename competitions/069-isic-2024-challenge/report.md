# #069 ISIC 2024 振り返り

陽性率 0.098% の病変分類で、未知患者に対する高感度域の pAUC を比較した。全候補は `patient-v1` の同じ5分割で評価した。

## CV の結果

| 構成 | OOF pAUC | OOF log loss | 確率 0 / 1 の件数 |
|---|---:|---:|---:|
| B00 病変メタデータ | 0.020184 | 0.062310 | 400,631 / 306 |
| E01 形状・色差 | 0.019982 | 0.059973 | 400,693 / 271 |
| E02 患者内相対特徴 | 0.020239 | 0.059283 | 400,675 / 272 |
| E03 陽性重み5倍 | 0.022024 | 0.180435 | 398,908 / 1,664 |
| E04 学習時の陰性抽出 1:5 | 0.155430 | 0.156235 | 0 / 0 |

E01 と E02 はベースラインとの差が事前の同点許容差 0.0005 以内だった。スコアの大半がゼロに飽和していたため、特徴の効果を安定した学習条件で再確認する余地がある。E03 は順位指標を改善したが、log loss が 0.062310 から 0.180435 に増えた。

21位の解法から着想した E04 は、同じモデル・特徴の学習 fold 内だけで、陰性を陽性の5倍まで抽出した。5 fold の pAUC は 0.17674、0.14210、0.15452、0.15938、0.14721。OOF ROC AUC は 0.94339。強い順位改善とともに、ベースラインより高い log loss も観測した。単一 seed の比較で、抽出比・学習率・木の葉の制約を変えた場合の効果は未検証。

## 患者当たり病変数別の誤り

E04 の全 OOF で感度 80% に初めて達する閾値 0.00711862 を、事後のエラー診断に使った。見逃しは全陽性393件中78件、誤検出は陰性400,666件中30,223件。

| 患者当たり病変数 | 評価病変数 | 陽性数 | 見逃し | 誤検出 |
|---|---:|---:|---:|---:|
| 1–115 | 15,995 | 32 | 7 | 1,812 |
| 116–241 | 45,618 | 77 | 14 | 3,935 |
| 242–477 | 90,677 | 93 | 16 | 7,422 |
| 478–9,184 | 248,769 | 191 | 41 | 17,054 |

誤検出率は病変数の少ない群から順に約 11.4%、8.6%、8.2%、6.9%。最多病変群に誤検出の絶対数が集中した。最少病変群の陽性は32件で、見逃し率の群間差には標本数の影響がある。

同じ診断は `uv run python competitions/069-isic-2024-challenge/src/analyze.py B00 E01 E02 E03 E04` で再計算できる。

## 最終モデルと外部評価

P6 計画で B00、E01〜E03 を新しい ID で再計測すると、4構成とも初回と同じ OOF pAUC だった。保存 OOF を全候補で再採点し、E04 を選定した。F00 は E04 と同じ規則で全量データの陽性と抽出陰性から学習し直したモデル。公開サンプル3病変で Notebook を実行し、ID 順と予測が export の CSV と一致することを確認した。 [最終選定記録](selection-p6.json) · [実験ログ](experiments.jsonl) · [知見カード](../../knowledge/K058-negative-subsampling-for-rare-positives.md)

Kaggle の最初のプレビュー実行がキャンセルされたため、F01 では入力ディレクトリの探索だけを変更した。F00 と F01 のモデルは同一ハッシュで、提出サンプルの予測は一致した。ダミー Notebook v2 の Late Public・Private はともに 0.02000。 [最終 Notebook](https://www.kaggle.com/code/shion5/kumite-isic-2024-final)

2026-11-27 の Late Submission で、F01 は Public **0.15980**、Private **0.14107**。OOF との差はそれぞれ +0.00437、−0.01436。Public は CV の fold スコア範囲に入り、Private は fold 最小値 0.14210 を約 0.00103 下回った。外部データでも定数予測の 0.02000 を上回ったが、Private への移行で順位性能は低下した。採点先の病変別ラベルと予測は取得できないため、低下の要因分析には保存 OOF を用いた。 [採点証跡](submission-audit.json)
