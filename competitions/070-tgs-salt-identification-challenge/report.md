# #070 TGS Salt Identification Challenge 振り返り

## ベースライン

101×101 の地震画像から塩領域を予測した。BCE で学習した小型 U-Net に固定閾値 0.50 を適用した E00 は、5-fold OOF で 0.69978、fold 別で 0.61900〜0.74550。Late Submission の5モデル多数決は Public 0.75086、Private 0.77971 だった。

| 正解の塩被覆率 | 件数 | E00 OOF |
|---|---:|---:|
| 空 | 1,562 | 0.81178 |
| 0%超〜10% | 576 | 0.20799 |
| 10%超 | 1,862 | 0.75795 |

空の正解に対するスコアは空判定の正解率に等しい。小面積の非空画像は同じ画素数のずれでも IoU が下がりやすく、E00 では最も難しい層だった。

## 自力の仮説

- **E01 閾値校正**。内側検証で選ばれた閾値は fold 順に 0.60、0.70、0.55、0.45、0.60。OOF 差は +0.00033（グループ単位のペア bootstrap 95% 区間 −0.00344〜+0.00421）。空マスクの正解率は 0.81178→0.83035、小面積のスコアは 0.20799→0.19167。空画像への誤検出は減ったが、小領域では悪化し、全体で改善を確認できなかった。
- **E02 BCE＋soft Dice**。OOF 差は −0.05318（95% 区間 −0.08217〜−0.00666）。小面積のスコアは 0.20799→0.17691 と悪化し、事前仮説を支持しなかった。一方、fold 0 の重複グループ80枚は E00 が全件誤検出、E02 が全件空判定で、fold 0 だけ全体スコアが改善した。重複グループを一単位として再標本化したため、このまとまった差が区間に反映される。
- **E03 学習時左右反転**。OOF 0.73200、E00 比 +0.03223（95% 区間 +0.00724〜+0.07415）。5 fold 中4 fold で改善した。被覆率別では空マスクが +0.06594、小面積が +0.00122、その他が +0.01353。改善は空画像の判定に集中した。

## 上位解法

- **1位 b.e.s. & phalanx**。複数モデルのアンサンブルで擬似ラベルを作り、段階的に自己学習した。最終推論では左右反転 TTA を用いた。 [チームの writeup](https://www.kaggle.com/competitions/tgs-salt-identification-challenge/writeups/b-e-s-phalanx-1st-place-solution-with-code) · [チームの論文](https://arxiv.org/abs/1904.04445)
- **5位 Kent AI Lab**。空かどうかを判定する分類と領域セグメンテーションを分けた。空マスクの多さを、セグメンテーションの損失だけで扱う場合とは異なる設計。 [チームの writeup](https://www.kaggle.com/competitions/tgs-salt-identification-challenge/writeups/peiyuan-liao-ding-han-renan-kent-ai-lab-ding-han-r)
- **14位 Argus**。画像境界を補完して入力し、タイルをモザイクに組み直して近接タイルを同じ fold に入れる分割と、モザイクを利用した後処理を採用した。 [チームの公開コードと README](https://github.com/lRomul/argus-tgs-salt)

E04 は1位解法の左右反転 TTA を E00 に追加し、元画像と反転を戻した画像の画素確率を等重みで平均してから、同じ 0.50 で二値化する。学習は追加せず E00 のチェックポイントを使う。

E04 の OOF は 0.71370、E00 比 +0.01393（95% 区間 +0.00898〜+0.01908）。空マスクが +0.02753、小面積が +0.00087、その他が +0.00655 だった。学習時と推論時の反転はそれぞれ単独で比較した。両方を組み合わせた効果、擬似ラベル、空判定用の別モデル、モザイク単位の検証は未検証。

## 最終選定

候補 E00〜E04 を OOF で比較し、首位の E03 は E00 に対するペア差の区間下限が正だったため採用した。2026年11月22日（日本時間）、5 fold の二値マスクを多数決した `E03/submission.csv` を最終提出として固定した。

重複グループ80枚に限ると、E03 は全件で空と判定し、E00 と E04 は全件で誤検出した。このグループを除く事後集計の OOF は E00 0.71406、E03 0.72653、E04 0.72827。学習時反転の全体での優位には、このグループの寄与が大きい。テストにも同じ画像グループが430枚あり、外部評価と OOF で重複の扱いと推論するモデル数が異なる。

## 外部評価

| 構成 | OOF | Late Public | Late Private |
|---|---:|---:|---:|
| E00 ベースライン | 0.69978 | 0.75086 | 0.77971 |
| E03 学習時左右反転 | 0.73200 | 0.74718 | 0.78082 |
| 差 | +0.03223 | −0.00368 | +0.00111 |

Private の改善は小さく、Public では悪化した。OOF での改善幅は外部評価では再現しなかった。単一モデルの OOF と5モデル多数決の違い、テスト側の難易度や重複画像の影響は切り分けられていない。Late の各スコアは選定後の照合に使い、実験ログの `late_score` には Private を記録した。

閾値校正の結果は [K002](../../knowledge/K002-calibrate-on-submission-form.md)、左右反転の結果は [K023](../../knowledge/K023-horizontal-flips-for-segmentation.md) に記録した。

## 選定の事後監査

現行の入力ハッシュ・グループ・fold を各 run の記録と照合し、OOF を再採点した。提出後に作成した [selection.json](selection.json) に、採用 run・比較結果・ハッシュを保存した。当時と同じ全件評価の規則で E03 の採用を再現した。

E03 の5チェックポイントをハッシュ照合して CUDA で再推論した。外側検証の二値マスクとテストの5モデル投票平均は保存配列と完全一致し、再生成した提出 CSV の SHA-256 も一致した。確認範囲は同一環境での保存済み重みからの推論。

| 評価条件 | E00 OOF | E03 OOF | E03 − E00（95%区間） | E04 OOF | E04 − E00（95%区間） |
|---|---:|---:|---:|---:|---:|
| 全4,000枚 | 0.69978 | 0.73200 | +0.03223 [ +0.00724, +0.07415 ] | 0.71370 | +0.01393 [ +0.00898, +0.01908 ] |
| 重複グループを除外 | 0.71406 | 0.72653 | +0.01247 [ +0.00546, +0.01959 ] | 0.72827 | +0.01421 [ +0.00903, +0.01952 ] |
| 全3,921グループを等重み化 | 0.71387 | 0.72660 | +0.01273 [ +0.00571, +0.01987 ] | 0.72808 | +0.01421 [ +0.00900, +0.01948 ] |

等重み化ではグループ内の画像別スコアを平均し、各グループを1件とした。各条件でグループ単位のペア bootstrap を1万回実施した。E03 と E04 の E00 に対する差は3条件すべてで正の区間を保った。E03 と E04 の区間はそれぞれ基準との差を表し、両者間の差は検定していない。
