# #072 Severstal: Steel Defect Detection 振り返り

## 結果

全空マスクの Late Submission は Public Dice 0.85674、Private Dice 0.85560。公式 Dice では空の正解に空を予測すると1点になるため、空マスクの多さだけでこの値に達する。

学習画像12,568枚のうち5,902枚に欠陥注釈がない。全空予測のローカル Dice は0.85887。クラス2では非空注釈が247件で、全空でもクラス Dice は0.98035になる。モデルは欠陥あり Dice と空マスクの誤検出率を分けて比較した。

E00-r2 の OOF Dice は **0.90618**。欠陥あり Dice は0.55694、空マスクの誤検出率は3.64%、小欠陥の全見逃し率は21.21%だった。クラス2の Dice は0.97882で、全空より0.00153低い。平均 Dice の改善はクラス2にも及ぶという判定には使えない。

E01 は欠陥あり Dice と小欠陥の全見逃し率を改善した。画像×クラスの85.89%を占める空マスクで誤検出が増え、全体 Dice は0.28264悪化した。評価閾値を固定した場合の結果で、閾値を再調整したときの効果は未検証。

E03 の面積ゲートで全体 Dice は +0.00188（画像単位ペア bootstrap の95%区間 +0.00151〜+0.00226）。面積32画素以上の予測の Dice は全件一致し、32画素未満の予測は空にしたときの値と全件一致した。誤検出率は −0.22ポイント、小欠陥の全見逃し率は +0.84ポイントだった。

E02 で小欠陥の Dice は0.47225から0.48211に上がった。クラス3の全体 Dice は +0.02975、クラス1は −0.02318で、元解像度の効果はクラスごとに異なった。全体の差は +0.00077（画像単位ペア bootstrap の95%区間 −0.00114〜+0.00261）。

## 上位解法の着眼点

- **4位 Wonderbolts** は分類とセグメンテーションを同じネットワークで学習し、画像分類の確率を画素確率に掛けた。空マスクの判定を分類の出力に任せ、非空 Dice をモデル選定に用いたと報告している。[本人 writeup](https://www.kaggle.com/competitions/severstal-steel-defect-detection/writeups/ods-ai-wonderbolts-4th-place-solution)
- **9位 Jacek Popławski** は4出力の独立分類器で画像ごとの欠陥有無を予測し、欠陥クラスごとのセグメンテーションの実行を絞った。分類器の予測はクラス別セグメンテーションの学習画像の選別にも使った。[本人 writeup](https://www.kaggle.com/competitions/severstal-steel-defect-detection/writeups/jacek-poplawski-step-by-step-9th-place-solution)
- **10位 Alexey Rozhkov** は欠陥ごとにセグメンテーションを別学習した。独立分類器を試し、最終的にクラス1にだけ使った。クラス全体に分類器を適用する有効性は解法間で揃っていない。[本人 writeup](https://www.kaggle.com/competitions/severstal-steel-defect-detection/writeups/ods-ai-alexey-rozhkov-10th-place-solution)

E04 は9位解法の独立した欠陥有無分類器だけを採用する。E00-r2 のセグメンテーションを使い、外側 fold の学習画像で別に学習した ResNet-18 の出力が0.5未満のクラスを空にする。空への誤検出が減る一方、見逃しが増えると予想する。

## 最終選定とエラー分析

E04 の OOF Dice は **0.92488**。E00-r2 比 +0.01870（画像単位ペア bootstrap の95%区間 +0.01725〜+0.02024）で5件中最高だった。欠陥あり Dice は0.50666、空マスクの誤検出率は0.64%、小欠陥の全見逃し率は36.92%。ゲートは空の正解に対する誤検出を1,297件取り除き、非空の正解に対する予測も750件消した。区間は画像の再標本化に基づき、学習の seed を変えた変動は未検証。

| 画像とクラス | 観測 |
|---|---|
| `53f9c84f6.jpg`、4 | 欠陥なし画像への140,483画素の誤検出をゲートで除いた |
| `dfcc8d751.jpg`、3 | 正解5,828画素。基準 Dice 0.96741 の予測をゲートが全て消した |
| `ac6d3cefd.jpg`、3 | 欠陥なし画像への140,459画素の誤検出が残った |
| `354760e3e.jpg`、3 | 正解140画素の小欠陥を基準と E04 の両方で見逃した |

最終分類器は全学習画像で学習した。セグメンテーションの全テンソルが全件学習済みのベースラインと一致することを確認し、最終モデルで公開テスト5,506枚分の提出形式を検証した。

## Kaggle 外部評価

| モデル | Late Public Dice | Late Private Dice |
|---|---:|---:|
| 全空ダミー | 0.85674 | 0.85560 |
| E00-r2 の全件学習 | 0.84655 | 0.85225 |

E04 の改善方向は OOF と Late Public・Private で一致した。ベースラインとの差は OOF +0.01870、Public +0.03758、Private +0.03134。最終 Private は全空ダミーを0.02799上回り、最終 OOF を0.04129下回った。

ベースラインの Private は OOF を0.05393、全空ダミーを0.00335下回った。クラス2の非空予測率はベースラインの OOF で0.70%（88 / 12,568）、Kaggle の公開実行環境で4.20%（231 / 5,506）だった。学習済みモデルとデータの両方が異なり、隠しテストの正解ラベルも得られないため、スコア差の原因は特定できていない。
