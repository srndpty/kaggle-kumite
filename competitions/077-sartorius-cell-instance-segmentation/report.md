# #077 Sartorius - Cell Instance Segmentation 振り返り

P4 では重複除去後に小さく削れた候補を棄却する E03 が最良だった。P6 では E03 を再学習した S00 を最終モデルに選定した。

## 結果

- 採点疎通用のダミー提出は Late Public・Private ともに 0.000。
- Baseline E00 の OOF は 0.21658。fold は 0.21646 / 0.20562 / 0.22770。
- 最終モデル S00 の OOF は 0.23359。fold は 0.23548 / 0.22237 / 0.24295。
- 選定記録 `outputs/selection-p6.json` の S00 を全量学習し、export F00 とした。Kaggle Notebook `shion5/kumite-077-final` v1 の Late Public は **0.262**、Late Private は **0.268**。選定は外部評価の前に確定済み。[Kaggle Notebook](https://www.kaggle.com/code/shion5/kumite-077-final)

Late Private は OOF より約 0.0344 高かった。CV は各 fold の学習部分で推論し、F00 は全 606 画像で学習している。学習量・隠しテストの構成・採点実装の寄与は切り分けていない。外部採点した学習済みモデルは F00 の 1 件なので、E03 の後処理による改善幅は保存 OOF で評価した。

E00 の画像平均 AP は、正解が 50 個未満の画像で 0.27773、150 個以上の画像で 0.13699。IoU > 0.50 で対応できた正解マスクは、100 px 未満で 908 / 6,633、100〜499 px で 29,602 / 57,377。小さい細胞や密集画像で取りこぼしが多かった。

## 自力の仮説で効いたこと・効かなかったこと

E01 の高解像度化で OOF は 0.21658 から 0.22907 に上がった。IoU > 0.50 で対応できた 100 px 未満の正解マスクは 908 から 1,115 に増えた。正解が 150 個以上の画像で平均 AP は 0.13699 から 0.15273 に改善し、取りこぼしも 31,073 から 28,929 に減った。

E02 の水平反転で OOF は 0.21329 に下がった。基準との差は −0.00329 で、3 fold すべてで同じ方向だった。

E03 では、E00 の保存済み候補を固定し、画素の重複除去で元面積の半分未満になったマスクを棄却した。OOF は 0.21658 から 0.23275 に上がった。IoU > 0.50 で数えた偽陽性は 25,309 から 17,173 に減り、偽陰性は 38,288 から 38,440 に増えた。偽陽性の減少 8,136 件のうち、5,255 件は面積 100 px 未満だった。

画像ごとの AP 差を撮影サンプル単位で再標本化した 95% 区間は +0.01504〜+0.01734 だった（403 サンプル、10,000 回、seed 42）。この区間は保存予測に対する後処理差を評価している。

正解が 150 個以上の画像での平均 AP は 0.13699 から 0.14424 に改善したが、取りこぼしは 31,073 から 31,216 に増えた。改善幅は細胞種別では astro が最大で、0.09673 から 0.12269 だった。

## 上位解法から学び、再現したこと

- 1 位の本人 writeup では、矩形ベースのインスタンス分割を使い、検出スコアと予測マスク内の平均確率で候補を再順位付けしている。P6 ではこの積だけを重複画素の割り当て順に導入する。[1 位解法](https://www.kaggle.com/competitions/sartorius-cell-instance-segmentation/writeups/rist-takuoko-tascj-1st-place-solution)
- 3 位の本人 writeup では、Mask R-CNN に、矩形を起点とせず画素から個体にまとめる Cellpose を混ぜている。細胞種別のモデルや TTA を使い、出力の異なるモデルを組み合わせた。[3 位解法](https://www.kaggle.com/competitions/sartorius-cell-instance-segmentation/writeups/not-experts-3rd-place-solution)

再順位付けの S01 は同じ OOF 候補で 0.23390。S00 との差 +0.00031 は事前の同点幅 0.001 以内だった。設定が単純な S00 を採用し、画像全体のスコア差から輪郭の改善を結論づけることは保留した。

## 最終モデルの OOF エラー分析

S00 の画像平均 AP は cort が 0.32046、shsy5y が 0.14868、astro が 0.12185。正解 50 個未満の画像では 0.29772、150 個以上では 0.14508 だった。IoU > 0.50 で拾えた正解の割合は 100 px 未満で 911 / 6,633（13.7%）、100〜499 px で 29,549 / 57,377（51.5%）、500 px 以上で 4,798 / 9,575（50.1%）。小さい細胞や密集した画像では、断片を除いた後も取りこぼしが残った。

LIVECell による事前学習、Cellpose とのアンサンブル、細胞種別のモデルと TTA は今回の比較に含めなかった。

## 既知の問題・未検証の事項

- CV の採点は公開仕様を最大一対一マッチングとして実装した。重複する正解に一つの予測が複数マッチするケースで、非公開の Kaggle 採点実装と一致するかは未確認。
- E03 と同じ設定・seed の S00 には OOF +0.00084 の再学習差があった。差の発生箇所は切り分けていない。
