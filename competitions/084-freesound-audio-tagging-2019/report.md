# #084 Freesound Audio Tagging 2019 の振り返り

## 採点環境と検証

公式の `test.zip` に対して、全クリップで固定タグ順位を返す非公開 Notebook を実行した。Kaggle の Late Submission は COMPLETE。表示値は Public 0.00000、Private 0.06791。 [採点した Notebook](https://www.kaggle.com/code/shion5/kumite-freesound-p0)

全80タグを含む curated 3 fold を比較に使った。完全一致の curated 1組を同じ fold にまとめ、curated と noisy の間に完全一致や調査条件での波形一致を検出しなかった。収録者の共有や、時間ずれ・編集を伴う重複は未検証。音声長の中央値は curated 4.68秒、noisy 15秒で、データ源とラベル品質に加えて長さにも違いがある。 [分割と実験条件](README.md)

## 実験結果

| Run | 構成 | OOF lwlrap | E01との差 | ペア bootstrap 95%区間 |
|---|---|---:|---:|---|
| E00 | タグ頻度 | 0.06833 | — | — |
| E01 | curated のみ。推論は平均集約 | 0.39561 | — | — |
| E02 | バッチの25%に noisy | 0.39898 | +0.00338 | [-0.00526, +0.01237] |
| E03 | E01 の重みで最大値集約 | 0.38802 | -0.00759 | [-0.01068, -0.00456] |
| E04 | 学習時に時間マスク | 0.36544 | -0.03016 | [-0.03531, -0.02511] |
| E05 | noisy の後に curated | **0.40982** | **+0.01421** | [+0.00525, +0.02313] |

- E02 は全体で小幅に改善したが、区間はゼロを含み、curated 正例50件以下のタグでは **-0.08136**。希少タグが恩恵を受けるという事前仮説と逆だった。
- E03 は2秒以下で差が実質ゼロ、5秒超で **-0.01489**。最大値集約で短いイベントを拾えるという仮説を、実際のイベント継続時間別には評価していない。タグが複数あるクリップでも **-0.01669** だった。
- E04 は2秒以下で **-0.04290**。短尺クリップで情報が失われる可能性がある。マスク位置・幅を変えた場合の効果は未検証。
- E05 は noisy を混ぜ続ける E02 と同じ延べ curated/noisy サンプル数で、順序を変えると **+0.01083**（95%区間 **[+0.00154, +0.01945]**）。fold 差は -0.00136、+0.04319、-0.00933 で、改善の寄与は fold 1 に集中した。E01 と比べて2–5秒で +0.03809、5秒超で +0.02395。2秒以下の1,498クリップで -0.01999、正例50件以下のタグ群（194正例）で -0.01771 だった。

E05 を主 OOF で固定した。区間は同じクリップの予測差から得たもので、別 seed や別データへの再現性は未検証。 [選定記録](selection.json) [実験ログ](experiments.jsonl)

## 外部評価

初回のモデル提出は E01 の3 fold 平均。第2版の非公開 CPU Notebook が COMPLETE になり、Kaggle の表示は Public 0.00000、Private 0.37736 だった。 [Baseline Notebook](https://www.kaggle.com/code/shion5/kumite-freesound-baseline)

事前に選んだ E05 を全 curated と noisy を使って再学習し、単一モデルで推論した。Private は **0.26984** で初回比 **-0.10752**、主 CV 比 **-0.13998**。Kaggle の Public 表示は 0.00000 だった。外部結果を見た後の再選定は行っていない。 [最終 Notebook](https://www.kaggle.com/code/shion5/kumite-freesound-final) [採点証跡](submission-evidence.json)

公開テストでは、最上位タグが両モデルで一致したクリップは25.38%。最上位に現れたタグは初回で70種類、最終で60種類。最頻タグは初回が `Sneeze` 274件、最終が `Tick-tock` 404件だった。これは予測順位の違いを示す。外部評価では fold 平均から全データ再学習の単一モデルにも変わったため、Private の差に対する段階学習と推論構成の寄与は分離できていない。

## 再現性

`RunStore` の9記録・49成果物のハッシュと、保存済み予測から計算した全 OOF スコアを照合した。全データ再学習の保存済み選定 JSON は選定時のものと同一。GPU 試走、再学習、データ読み込みと採点を含む記録済み実行合計は約18分50秒。ローカル学習の上限4時間内だった。

採点した両 Notebook の公開出力で、3,361件の ID 順、80タグの列順、予測の有限性と値域を確認した。最終重みでローカル再推論した公開テスト12件は、Kaggle の出力と最大絶対差 `1.17e-6` 未満で一致した。
