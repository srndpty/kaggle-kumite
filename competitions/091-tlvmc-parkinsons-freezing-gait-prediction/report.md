# #091 Parkinson’s Freezing of Gait Prediction 振り返り

## 結果

**実装・学習完了、外部評価未達。** 固定5 fold の比較実験と最終モデル E04 の選定を完了した。Kaggle の Late Submission は再提出でも形式エラーとなり、外部スコアは取得できなかった。追加の手がかりが得られるまで再提出を保留する。 [採点証跡](submission-evidence.json)

被験者単位で固定した5 fold で、採点対象11,153,202行の3クラス平均 AP を比較した。過去3秒の加速度統計を使う E04 が **OOF 0.13722** で最高だった。基準 E01 に対する差は +0.04078。
上位2件の点推定差 E04−E05 は +0.00168。被験者単位のペア bootstrap 200回による95%区間は [−0.00137, +0.00721]。差が0.005以下で区間がゼロを含むときは変更の少ない構成を採用するルールに従い、E04 を最終モデルに固定した。

## 自力の仮説検証

- 瞬時値に過去1秒の平均・標準偏差を加えると、全体 AP は +0.03291、5 fold すべてで改善した。差の大半は Turn の +0.09579。
- 1秒窓を中央揃えにすると全体で +0.00060 だったが、改善を予想した StartHesitation では −0.00030、DeFOG の平均 AP は −0.00449 だった。
- 1秒窓を過去3秒へ延長すると、Turn は +0.03172、Walking は +0.00059。StartHesitation では −0.00870 で、全体の改善と方向が異なった。

## 上位解法を参考にした比較

2位解法から収録種別ごとのモデル学習を取り入れた。E05 は E04 の3秒窓と学習設定を固定し、各 fold で別々のモデルを学習した。tDCS FOG の平均 AP は +0.00106、DeFOG は −0.00795、全体は −0.00168。DeFOG の Turn の低下が大きかった。GRU、推論時の系列長変更、疑似ラベルは未検証。10位解法の共通 U-Net と重複窓アンサンブルも未検証。 [2位の本人 writeup](https://www.kaggle.com/competitions/tlvmc-parkinsons-freezing-gait-prediction/writeups/waiwai-2nd-place-solution) [10位の本人 writeup](https://www.kaggle.com/competitions/tlvmc-parkinsons-freezing-gait-prediction/writeups/james-day-10th-place-solution-u-net-with-squeeze-e)

## 誤差分析と外部評価

StartHesitation の陽性行の77.8%が1人に集中した。その被験者の検証行だけを除いた事後診断では、E02 と E04 の StartHesitation AP は 0.01396 と 0.01257。3秒窓による低下は小さくなったが、方向は変わらなかった。全体 AP は E02 0.11922、E04 0.12316、E05 0.12043。モデルは作り直さず、同じ OOF の採点対象だけを変えた。

Kaggle 上の公開テストでは E01 と E04 が完走し、各286,370行の ID と予測値がローカルの保存結果と完全に一致した。初回のダミー3版とモデル2件に加え、E04 の提出 ID を辞書順にした再提出も採点時の形式エラーだった。Kaggle の個別提出 API は一般的な形式エラーだけを返した。Public と Private のスコアは取得できず、CV の改善が外部評価でも再現するかは未確認。 [採点証跡](submission-evidence.json)
