# #092 G2Net Gravitational Wave Detection

## 比較結果

| Run | 変更 | OOF ROC AUC | fold 別 ROC AUC |
|---|---|---:|---|
| B00 | 未処理の Hanford 波形を 1D CNN に入力 | 0.50067 | 0.49887 / 0.50254 / 0.50157 |
| E01 | 25〜500 Hz の帯域制限 | 0.72396 | 0.73170 / 0.73428 / 0.73820 |
| E02 | 外側学習 fold で推定した PSD で白色化 | 0.73009 | 0.72835 / 0.72956 / 0.73244 |
| E03 | Livingston と Virgo を追加 | 0.78815 | 0.78765 / 0.78794 / 0.78972 |

560,000 波形を完全重複グループ単位で層化 3-fold に分け、seed 42、バッチサイズ 256、3 エポックで比較した。元ノイズ区間・注入元の識別キーが配布データにないため、完全重複で検出できないノイズ共有は評価の限界として残る。[分割と実行条件](README.md)

- 帯域制限による全体 OOF AUC の改善は +0.22328。学習波形の標本では、対象帯域に含まれる Hanford のパワー比は中央値 0.141% だった。入力モデルと学習条件を揃えた比較で、帯域を事前に絞る効果を確認した。
- 白色化では全体 OOF AUC が +0.00614、fold 内 AUC は 3 fold とも低下した。予測中央値は E01 で 0.287〜0.456、E02 で 0.409〜0.410 だった。AUC を全 OOF に適用すると fold をまたぐ順位も評価されるため、fold 内の識別力の変化と併記した。fold とラベルで層化した行単位のペア bootstrap 300 回（seed 42）で、全体 AUC 差の 95% パーセンタイル区間は +0.00529〜+0.00700。保存済み予測の比較であり、再学習による変動は含まない。
- 検出器を 1 台から 3 台に増やすと、白色化を揃えた条件で OOF AUC が +0.05806、各 fold の AUC も改善した。Livingston と Virgo の個別寄与は未検証。

## 上位解法との比較

1 位 KDL の初期構成から Hanford と Livingston のチャネル入れ替えを切り出し、P4 の選定構成 E03 を再実行する E04 と比較した。E04 の OOF AUC は 0.78815 で、E03 と OOF・テスト予測のハッシュが一致した。入れ替えを加えた E05 は OOF AUC 0.78642（差 −0.00173、同じ方法の 95% ペア bootstrap 区間 −0.00241〜−0.00094）で、fold 内 AUC も全 fold で低下した。KDL の人工データ事前学習と個別エンコーダーの統合や、2 位 EventHorizon の学習可能な時間周波数変換は今後の検証対象として残る。 [1 位本人の解法](https://www.kaggle.com/competitions/g2net-gravitational-wave-detection/writeups/kdl-top-1-solution-deep-learning-part) · [2 位本人の公開コード](https://github.com/analokmaus/kaggle-g2net-public)

## 外部評価

公式テスト 226,000 行の定数 0.5 は Late Public・Private AUC ともに 0.50000。B00 と同じ構成の B00-initial を使用した F00-baseline は OOF AUC 0.50067、Late Public AUC 0.50281 だった。いずれも提出経路の確認に使用した。

2026-11-26、事前計画に沿って E04・E05 の保存 OOF を再採点し、E04 を選定した。選定記録は `outputs/selection-p6.json`。E04 の検証済みの保存テスト予測（3 fold の確率平均）を F00 として export し、Kaggle に提出した。Late Public AUC は **0.80164**、Late Private AUC は **0.79573**。Private は全体 OOF 0.78815 より +0.00758 だった。OOF の各行は 1 モデルで予測し、提出予測は 3 モデルを平均している。平均化と評価集合の違いの寄与は切り分けていない。

### エラー分析

E04 の保存 OOF を、検出器ごとの未処理 RMS の四分位で比較した。各区間は 140,000 行。AUC は全体で 0.78699〜0.78985 に収まり、RMS が高いほど悪化する傾向は観測されなかった。未処理 RMS は帯域外の成分を含み、信号対雑音比や帯域内の局所的な雑音とは異なる。
