# #093 Mechanisms of Action Prediction 振り返り

## 検証と採用モデル

化合物単位の 5 分割で、採点対象の 206 ラベルを全 23,814 行で評価した。独立 L2 ロジスティック回帰 E01-r3 の Log Loss は **0.035158**。遺伝子発現を外した E02-r3 は **0.020693** で、5 fold 全てで改善した。発現を 64 主成分に圧縮した E05-r3 も **0.023067** まで改善した。比較した条件では発現を外した方が良かった。測定値自体の有用性はモデル容量や正則化の設定に依存し得る。

E02-r3 と MLP の E04-r3 の OOF 差は **−0.001050**。保存済み OOF の行ごとの損失差を化合物 ID ごとに足し、同数のグループを復元抽出（seed 42、2,000 回）して得た 95% パーセンタイル区間は **[−0.002303, −0.000258]**。推定には元の OOF を用い、学習のやり直しによる変動は含めていない。

## ラベル頻度帯の誤差

学習全体の陽性行数でラベルを区切り、各帯のラベル別 OOF Log Loss を平均した。各 run の `label_losses.csv` から再集計できる。

E03-r3 の出現率への 10% 縮小で、最少頻度帯の損失は **−0.000470**（化合物単位 bootstrap 95% 区間 **[−0.000652, −0.000315]**）。全 206 列でも E01-r3 の 0.035158 から 0.023966 に下がった。MLP の改善は陽性 21 行以上の帯に表れた。E02-r3 の全体改善は主に陽性 81 行以上の帯から来ており、最少頻度帯はわずかに悪化した。

## 分割の診断

E01 の行シャッフル分割は **0.026924** で、化合物分割より **0.008234** 低かった。行分割で学習・検証に共通する化合物 ID は fold あたり 2,330〜2,362 件、主分割では 0 件。検証 fold に一度も陽性が現れなかったラベルは、行分割で 6〜11、主分割で 47〜73。未知化合物の性能を知るために主分割を使った。テストの化合物 ID は提供されておらず、外部採点での化合物共有率は不明。差には fold ごとの学習行と陽性の構成も影響し得る。

## 提出の再現性

初回の E01-r2 Notebook は Kaggle CPU で再学習した。公開テストの行・列は一致したが、ローカル CUDA 学習からの確率差は最大 0.5634 だった。そこで前処理と学習済み係数を固定して Notebook に同梱し、同じ推論実装で CV も再実行した。選定はこの実装で得た r3 の OOF を使った。

Kaggle 上で出力した公開テストの 3,982 行と 206 列をローカルと照合した。確率の最大絶対差は E01-r3 で **7.272×10⁻¹⁵**、E02-r3 で **1.110×10⁻¹⁶**。照合した両方の Notebook v1 を提出した。
