# #094 OpenVaccine: COVID-19 mRNA Vaccine Degradation Prediction

- URL: https://www.kaggle.com/competitions/stanford-covid-vaccine
- カテゴリ: G / 難度: 4 / 計算負荷: M
- 今回の比較実験テーマ: 位置別の系列予測、測定誤差付きラベルの扱い、対合確率（bpp）、学習と別ラウンドの配列への汎化
- 深さ: **Standard**

## コンペ概要

**RNA 配列と予測二次構造から、塩基ごとの分解されやすさ（3 条件）を予測する。**

- 分野: 生物・科学（配列）/ 系列
- 主催: Stanford 大学 Das 研究室・Eterna（Kaggle 上）
- 背景: mRNA ワクチンは加水分解で壊れやすく、冷蔵輸送が配布の障害になる。分解されにくい配列設計のために、塩基単位の分解予測モデルが必要
- 予測するもの: 各塩基の `reactivity`（SHAPE）、`deg_Mg_pH10`、`deg_Mg_50C`（採点 3 列）。提出は採点外の `deg_pH10`・`deg_50C` を含む 5 列
- 入力: 配列（ACGU）、ViennaRNA の MFE 構造（ドット括弧）、bpRNA のループ種別（7 種）、EternaFold の対合確率行列（bpp）
- 開催期間・参加チーム数: 2020-09-10〜2020-10-06、1,636 チーム（論文による）
- 参考スコア: 1 位の Private MCRMSE 0.3420。上位 3 チームも使った公開カーネルは Public 0.24860 / Private 0.36106、DegScore-XGB は Public 0.35854 / Private 0.43850（いずれも [Wayment-Steele et al. 2022](https://arxiv.org/abs/2110.07531) の記載）

## 基本情報（P0）

- 評価指標: MCRMSE（採点 3 列それぞれの RMSE の平均。小さいほど良い）。採点位置は各配列の先頭 `seq_scored`
- 提出形式: File（`id_seqpos` + 5 列の CSV、457,953 行）
- Late Submission: 可。2026-11-25 に公式サンプル（全 0）を提出し、Public 0.64846 / Private 0.71003 で採点された
- データ概要: 学習 2,400 配列（長さ 107、先頭 68 位置にラベル、5 目的と各測定誤差、`signal_to_noise`・`SN_filter`）。test 3,634 配列（長さ 107 が 629、長さ 130 が 3,005）。bpp 行列 6,034 個
- **Private 正解の公開**: `data/post_deadline_files/private_test_labels.csv`（2,493 配列、`test_filter` 列付き）。`test_filter == 1` の 1,172 配列 × 先頭 91 位置で全 0 提出を採点すると 0.71003 になり、Kaggle の値と一致した。この条件をローカル Private 採点（`data.private_score`）として固定した。**外部評価にだけ使い、選定には使わない**

## P1. EDA（`SN_filter == 1` の配列）

- 目的の分布: 平均 0.38〜0.46、標準偏差 0.43〜0.57。`SN_filter == 0` の配列は ±20〜±44 まで振れ、測定誤差の中央値は SN=1 の 2〜3 倍、最大は 3×10⁵
- 目的間の相関は 0.58〜0.87（`deg_Mg_pH10` と `deg_Mg_50C` が 0.872）
- 構造の効果が大きい: 対合（ループ種別 S）の平均 0.24、非対合（E・H・B・M・X）は 0.60〜0.73
- 位置の効果: 先頭 1〜3 位置が高い（位置 1 の平均 2.03）
- **配列の近さ**: 学習配列どうしの最近傍 5-mer Jaccard の中央値は 0.57（90% 点 0.80）。長さ 130 の test 配列から学習への最近傍は中央値 0.236 で、学習配列とは遠い

## P2. 検証分割

- リーク経路: 同じ設計者による配列の小さな変種（近縁クラスタ）が学習と検証に分かれること。テストの公式分割もクラスタ単位で作られている（論文）
- 主分割: 5-mer 集合の Jaccard 類似度 ≥ 0.35 で連結成分を作り、GroupKFold（5 分割）。閾値は、検証配列→学習配列の最近傍 Jaccard の中央値が Private の値（0.236）に最も近い 0.35（0.261）を選んだ。0.30 では最大成分が 1,168 配列になり fold が組めない。`split_version = kmer5-jaccard0.35-groupkfold5-v1`
- 比較用: 分子単位のランダム KFold（最近傍中央値 0.525）
- 採点対象: 公式と同じく `SN_filter == 1` の 1,589 配列 × 68 位置 × 3 列。`SN_filter == 0` は学習には使えるが、CV の採点からは除く（`Labels.scored` で NaN にする）
- Quality Gate: `run.py` が `reserve_cv` → `publish_cv_run(gate=...)` を通し、`dense_oof` で OOF (2400, 68, 3) を再採点する。`SourceSpec` はリポジトリ root からコンペの `data.py`・`models.py`・`run.py`・`final.py` と、使う `src/kumite` モジュール・`pyproject.toml`・`uv.lock` を宣言する。手法の定義は `methods.toml`（ソース監査の対象外）に置き、各 run の実効設定を `settings` に封入する。手法を足しても既存 run の export を妨げないため

## P3. Baseline

- E00: 前後 4 位置の one-hot（塩基・構造・ループ種別）と位置・末尾までの距離による LightGBM（3 目的を個別、600 ラウンド固定）
- E01: 同じ入力の 2 層双方向 GRU（hidden 128、60 エポック固定、OneCycle）
- seed 揺れ: E00 と E00-s2 の差は 0.00039、E01 と E01-s2 の差は 0.00162（クラスタ bootstrap 95% 区間 [−0.00565, +0.00148]）。**同点許容差を 0.002 に固定**し、`selections.toml` に P4 の比較前に記録した。構成の単純な方を優先する

## P5. 上位解法の調査

Kaggle の議論ページは本文を取得できなかったため、主催者と上位入賞者の共著論文（[Wayment-Steele et al., Nat Mach Intell 2022](https://arxiv.org/abs/2110.07531)）と、1 位解法の主催者側の再構成（[eternagame/KaggleOpenVaccine](https://github.com/eternagame/KaggleOpenVaccine)、第三者）に基づく。本人 writeup・本人コードは読めていない。

- 1 位（Nullrecurrent）: 1D 特徴と、二次構造に基づく隣接行列などの 2D 特徴をマルチヘッド注意に入れ、CNN 層へつなぐ。公開カーネル（autoencoder・GNN・GRU）が土台で、上位 3 チームも利用（論文）
- 2 位（Kazuki2）: 疑似ラベルの実装例として論文に図示されている（論文）
- 共通点: 多くのチームが「疑似ラベル」と「Arnie の 5 種類の構造予測器で作った追加の入力（ランダム RNA を含む）」を決め手に挙げた（論文）
- 6 位: bpp 行列（または隣接行列）と配列特徴の積和によるグラフ畳み込み、7 位: bpp を注意の加算バイアスに使う自己注意（第三者の検索結果の要約に基づく。論文補遺は未確認）
- 論文の推測: SHAPE（reactivity）は S/N が高く、目的間で重みを共有すると分解データの予測にも効く

## P6. 着眼点の再現

- 疑似ラベル（E07）: fold ごとに E06 と同じ設定の教師を、その fold の学習行だけで学習し、test 全配列（長さ 107・130）の全位置に疑似ラベルを付けた。要素重みは学習行の重みの中央値 × 0.5（実験前に固定）。検証ラベルが疑似ラベルに入らない（K004）
- 再現しなかった着眼点: Arnie による別構造の入力拡張（EternaFold・CONTRAfold などが未導入）、注意機構・CNN の併用
- 6 位のグラフ畳み込みは、E02 の `bpp @ onehot`（1 層・学習なしの集約）に近い

## P7. 最終評価

- 選定計画 `final`（候補 E06-r2 → E07、許容差 0.002）。`final.py select final` で E07 を選定し、`outputs/selections/final.json` に記録した。**この計画は E07 の実行後に書いた**。許容差と優先順の規則は P3 で固定したものに従い、候補は現行コードで export できる run（コードの一般化後）に限った。E01〜E06 は一般化前のコードで学習したため、Gate の export 対象にならない
- export: `final.py export final X01` → `outputs/exports/outputs/runs/X01/submission.csv`（E07 の fold 平均 test 予測。Gate が選定記録・ソース・設定・候補の OOF を再検証）
- Late Submission（2026-11-25、X01）: **Public 0.25489 / Private 0.37334**。ローカル Private 採点（0.37335）と一致
- CV と外部評価: CV 0.25112 ≈ Public 0.25489 だが、Private は 0.122 悪い
  - Public は学習と同じ設計ラウンド（RYOS-I）、Private は大会開始後に集めた別ラウンド（RYOS-II、長さ 130）（論文）
  - 位置で分けると、学習で見た位置（0〜67）は 0.39264、外挿位置（68〜90）は 0.30904。**外挿位置の方が小さく、差は長さの外挿によるものではない**
  - Private のラベルは学習より散らばりが大きい（列別の標準偏差 0.47〜0.74、学習 SN=1 は 0.46〜0.52）。この散らばりの違いがどの程度効いているかは未分離
  - クラスタ分割でも CV と Private の差は E00 で 0.113、ランダム分割では 0.135。分割の工夫で縮むのは一部だけ
- CV と Private の向きの逆転: E05（5 目的）は CV −0.0066 / Private +0.0024、E03 と E04 の順位は CV と Private で逆。単一 seed の Private 差（0.002 程度）は Private 側の揺れと区別できていない
