# #094 OpenVaccine: COVID-19 mRNA Vaccine Degradation Prediction 振り返り

## 結果

- 最終モデル E07（双方向 GRU + bpp 特徴 + 逆分散重み + 5 目的同時学習 + fold 内教師による疑似ラベル）
- 類似配列クラスタ 5 分割の OOF MCRMSE 0.25112。Late Submission は Public 0.25489 / Private 0.37334（1 位は Private 0.3420、公開カーネルは 0.36106）
- CV と Late の差:
  - **説明できた範囲**: CV と Public はほぼ一致し、差は Private だけで大きい。Private は学習と別の設計ラウンドで集めた配列で、5-mer の最近傍類似度も学習配列どうしより大幅に低い（中央値 0.236 と 0.57）。位置で分けると外挿位置（68〜90）の誤差の方が小さく、長さの外挿は主因ではない
  - **切り分けられていない要因**: 配列の新しさ（設計の違い）と、測定ラウンドの違い（ラベルの散らばりが学習より大きい）のどちらがどれだけ効いているか。クラスタ分割で CV を Private の条件に近づけても、縮んだのは差の一部（0.135 → 0.113）だけ

## 自力の仮説で効いたこと・効かなかったこと

- 効いた: 系列モデル（GRU が位置窓 LightGBM より CV −0.029 / Private −0.037）、荒れたラベルの減衰（SN=0 除外で CV −0.019、逆分散重みで −0.025。Private でも −0.010〜−0.012）、bpp 特徴（CV −0.008 / Private −0.008 と内外でそろう）
- CV だけで効いた: 5 目的の同時学習（CV −0.0066、Private +0.0024）。除外と逆分散重みの優劣も CV と Private で逆。いずれも Private 差は 0.002 程度で、単一 seed の Private の揺れと区別できていない
- 外れた予想: 長さ 130 の外挿位置で誤差が大きくなる（実際は小さい）。ランダム分割の楽観（0.021）はあったが、Private との差の大半は分割の問題ではなかった

## 上位解法から学び、再現したこと

- 出典は主催者と入賞者の共著論文と、主催者による 1 位の再構成コード（本人 writeup は取得できず）
- 疑似ラベル: fold ごとに学習行だけで教師を作り、test 全配列に疑似ラベルを付けて加えた。CV −0.0057（bootstrap 95% 区間 [−0.0069, −0.0041]）、Private −0.0023。Private の改善は CV の半分以下
- 重みの訂正: 「重み 0.5×中央値」のつもりが、疑似ラベルだけのバッチではバッチ内の正規化で相殺され、E07 の寄与は実効的に 1 倍だった。損失に組の係数を掛ける形に直した E08（実際に 0.5 倍）は E07 と実質同点（−0.0002、区間は 0 をまたぐ）。この範囲では疑似ラベルの強さに CV は敏感でない

## 上位解法との差分（試さなかった着眼点）

- Arnie の複数の構造予測器（EternaFold・CONTRAfold など）による入力の拡張とランダム配列の追加。上位チームの多くが決め手に挙げていた
- 注意機構と CNN の併用、bpp を注意のバイアスにする構成、学習するグラフ畳み込み
- 複数 seed・複数アーキテクチャのアンサンブル

## 既知の問題・未検証の事項

- 最終選定の計画は E07 の実行後に書いた（許容差と優先順は P3 で固定した規則に従った）。差は許容差の約 3 倍で、候補の順を逆にしても結論は同じ
- P3 の後から Private を観測しており、P4 の手法の定義もその後だった。選定コードは CV だけを使うが、方針が Private の影響を受けなかったとは証明できない（README の時系列を参照）
- 提出は CV 公開時に保存した fold 平均の test 予測で、export 時に推論を再実行して同値性を確かめてはいない
- `dev check` は #090 の不安定なテスト（`test_shuffled_input_and_duplicate_steps`、3 回中 1 回失敗）で失敗する。#090 には変更を加えておらず、別件として扱う
- E01〜E06 は GRU 学習関数の一般化前のコードで学習したため、Gate の export 対象にできない。E06 は再実行（E06-r2）で fold 単位まで同じスコアを再現した
- Private の改善・悪化（0.002 程度）は単一 seed。seed を変えた外部評価をしていない
- 逆分散重みの τ=0.3、疑似ラベル重み 0.5 は事前に決めた値で、調整していない

## 次のコンペに持ち越すこと

- 測定誤差がラベルと一緒に配られている場合は、除外より先に逆分散重みを試す。ただし CV と外部評価で優劣が逆転しうる
- 評価先が別の収集ラウンド・別の設計の場合、類似度クラスタ分割でも CV と外部評価の差は埋まらない。Public と Private のどちらが学習と同じ母集団かを先に確認する
- 疑似ラベルは fold 内の教師で作れば CV でリークなしに評価できる。別バッチにする場合、重みの一律倍はバッチ内の正規化で消えるので、寄与は損失の係数で変える
- 公開済みの Private 正解がある場合は、採点コードを選定経路から分け、最終選定記録の確定までは実行しない。選定計画は比較実験の前に commit する
- 手法の定義をソース監査対象外の設定ファイルに置き、run ごとの実効設定を証跡に封入すると、手法の追加で既存 run の export が壊れない。コード本体を変えたら最終候補は再実行する
