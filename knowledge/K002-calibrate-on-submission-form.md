# K002: 較正は提出と同じ形の予測で決める

- 状態: 再現
- 分類: 較正

## 仮説

温度スケーリングなどの後処理は、決めたときと同じ形（単一モデルか平均か）の予測に適用しないと、効果が逆転しうる。

## 観測

- #001 Otto: 単一モデルの OOF で温度 T を決める（クロスフィット）と、CV は -0.0025（5/5 fold 改善）。しかし 5 fold 平均の提出では Private +0.00075 と悪化した
- 入れ子の検証で再現: 単一モデルには -0.0023、平均予測には +0.0009。単一の OOF で決めた T は 1.093、平均予測に最適な T は 1.026
- モデルの平均で確率がならされ、過信の大半はそれで解消される。そこに T をかけると、確率を穏やかにしすぎる

- #060 State Farm（画像 10 クラス、ResNet50 の fine-tune。NN の出力）: 同じ向きで、大きさは Otto の 10 倍以上
  - 入れ子の疑似テスト（外側の学習行の内側 4 分割）で、外側の学習行の内側 OOF（単一モデルの形）で T を決めると 1.32〜1.39（5 fold すべてで 1 より大きい）
  - その T は、単一モデルの予測には -0.034 効くが、4 モデルの平均には **+0.028 悪化**（運転手単位 bootstrap 95% 区間 [+0.014, +0.041]）。平均に最適な T は 0.82〜1.08
  - test の中の近傍の予測との平均（K012）の後に、同じ形（単一 + 近傍）で決めた T（1.00〜1.08）も、平均 + 近傍には +0.0035 悪化した。平均 + 近傍に最適な T は 0.59〜0.85 で、むしろ鋭くする方向
  - 揺れを均す処理（モデルの平均・近傍の平均）は互いに効果が重なる。後処理の効果は、提出と同じ形の予測で測る必要がある（近傍の平均も OOF で -0.114、提出の形で -0.053）

- #019 Rossmann（別の仕組みでの関連する観測）: 予測に掛ける係数を、外側の各分割の学習期間の中だけの内側の時系列 CV で決めると（0.979・0.983・0.992）、CV で悪化した（+0.0010、bootstrap 95% 区間 [+0.0007, +0.0013]）。窓ごとの最適な係数が 1.009・0.994・0.984 とばらつく。予測の形ではなく、期間によって全体の水準がずれることが原因で、ある期間で決めた後処理は別の期間に移らなかった
  - 当初（E11）は「他の検証窓の OOF」で係数を決めていた。時系列では未来の窓の売上と、自分の窓で学習したモデルの OOF を使うことになり、正しい評価ではなかった（+0.0006 と記録）。後処理のパラメータを決めるデータも、外側の学習期間の中に閉じる必要がある

## 適用条件

- 後処理のパラメータを OOF で決め、fold 平均の予測に適用する場合
- 時系列では、後処理のパラメータを決めた期間と適用する期間が違う。期間ごとの最適値のばらつきを先に確かめる

## 未検証

- Platt scaling・isotonic など他の較正手法
