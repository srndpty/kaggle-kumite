# K004: 全行で作った OOF 特徴を後段の CV に使うと、検証ラベルが学習側に入る

- 状態: 仮説
- 分類: 検証

## 仮説

近傍特徴・target encoding・スタッキングのメタ特徴などを全行について OOF で作り、同じ分割で後段の CV をすると、外側の検証行のラベルが学習行の特徴を通して漏れ、CV が楽観側に偏る。

## 観測

- #001 Otto: 旧実装（E09: クラス別の最近傍距離、E10: スタッキング）はこの構造だった
- nested 化（外側の学習行だけで、内側 fold の OOF として作る）した E11・E12 は、旧版よりむしろ良かった（-0.0055、-0.0027）。ただし nested 化では、検証・テスト行の特徴が「内側の参照集合 4 つの平均」になるという別の変更も入る
- 切り分け（E13: 参照集合 1 つ）では、平均化の効果が -0.0074、リークの遮断（参照集合の縮小を含む）が +0.0019。このデータでは楽観バイアスは 0.002 程度以下だった
- nested 版の提出（E12）は、CV では旧 E10 より良いのに Private は +0.0015 悪かった。1 段目を train の 60% で学習していることが一因と考えられるが、平均のとり方やメタ特徴の分布も変わっており、原因は特定できていない
- 外側の検証ラベルを別のクラスに変えても入力特徴が変わらないこと（label perturbation test）で、nested 版にリークがないことを確認した
- #019 Rossmann（時系列分割）: 店舗別の売上統計量を、分割ごとに学習行（検証窓より前）だけから作った。学習行の統計量に自分の売上を含めるかどうか（E04 と E05）の差は +0.0003 で、ノイズの範囲だった（1 店舗あたり数百行の平均なので、1 行の影響は小さい）
  - 同じ比較をランダム分割で行うと、自分の売上を含めた方が -0.0042（3/3 分割）と良く見えた。自分のラベルを含む特徴の評価は、分割の仕方に左右される（K007）
  - 注意: E04 の「自分の期間以外」には、自分より未来の期間の売上も入る。E04 と E05 の差は時間的な参照集合の違いも含み、「自分の売上を含めることだけの効果」ではない。時系列では、外側の検証ラベルを守るだけでなく時間の向きもそろえる必要がある（K008。そろえた E12 は E04 比 -0.0057）

## 適用条件

- ラベルを使って作る特徴を、後段のモデルの CV に入れる場合すべて。バイアスの大きさはデータ次第で、Otto では小さかったが一般には大きくなりうる（target encoding で高カーディナリティのときなど。未検証）
- Late Submission で改善しても、CV にリークがないことの証明にはならない
- リークは CV の推定を歪めるが、提出物を不正にするわけではない。CV の推定は nested、提出用の 1 段目は多くのデータで学習する、と分けるのが合理的と考える（未検証）

## 未検証

- target encoding など、他の種類のラベル依存特徴でのバイアスの大きさ
- スタッキングでのリーク遮断と平均化の切り分け

## 次の検証機会

- target encoding を使う表形式コンペで、旧方式と nested 方式の CV の差を測る
