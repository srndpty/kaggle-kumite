# K011: グループ分割とランダム分割の差は、データと学習条件によって変わる

- 状態: 条件付き
- 分類: 検証

## 仮説

同じグループ（人・動画・患者など）の行が互いによく似ていて、test のグループが学習と別のとき、行をランダムに分けると検証行とほぼ同じ行が学習側に入り、楽観的な評価になり得る。ほぼ重複した動画フレームでは、差が桁違いになり、augmentationの採否も逆転した。ただし、人のIDがあるというだけで、ランダム分割が常に高い精度になるとは限らない。分割は評価したい予測先の条件から決める。

## 観測

- #060 State Farm（画像 10 クラス、logloss。運転手 26 人の動画のコマ、test の運転手は別人）
  - 診断: 32x24 の小画像の 1-NN の正解率が、ランダム分割で 99.4%、運転手単位の分割で 40.5%。test から学習への最近傍の相関（0.885）は運転手単位の検証（0.896）に近く、ランダム分割（0.994）とは違う
  - 楽観: 同じ 22,424 行を評価して、凍結特徴 + LR が 1.079 と 0.035（30 倍）、fine-tune が 0.386 と 0.020（19 倍）
  - 採否の逆転: augmentation を外すと、運転手単位では +0.056 悪化、ランダム分割では -0.0038 改善（運転手単位 bootstrap の区間 [-0.006, -0.002]、18/26 人で改善）
  - 外部評価: fine-tune の Late は Public 0.341 / Private 0.268。運転手単位の値に近く、ランダム分割の値とは 1 桁違う

- #083 TensorFlow Speech Recognition（音声12クラス、Accuracy。話者1,881グループ・背景録音6本）
  - 同じ65,119行・log-mel小型CNN・クラス均等抽出・20epochで比較。話者／背景録音を分けた3foldの平均Accuracyは0.856265、行単位層化3foldは0.715365。ランダム分割の方が低く、元の強い一般化の反例になった。
  - ランダム分割のfold Accuracyは0.835583・0.710357・0.600157で、学習結果の変動も大きい。分割方式だけでなく学習行の組合せ・抽出順序も変わるため、差を話者依存だけに帰属しない。
  - 主分割では話者・背景録音の共有は0。ランダム分割の共有率はoutputs/split_diagnostic.jsonに保存した。高いCVを得るために主分割を選んだわけではなく、未知話者への汎化を評価するために実行前に固定した。
  - ランダム分割はseed42の1回だけ。augmentationの採否逆転は音声では調べていない。test話者との対応が不明で、どちらが外部評価の不偏な推定かは確定しない。

- #045 Quora Question Pairs（質問ペアの二値分類、Log Loss）
  - 質問ノードを分け、両端が同じ検証群に属する80,762ペアを同一条件で採点した。学習の総行数とラベル別件数を揃え、同一・逆順ペアを除いたうえで、検証と質問を共有できるようにすると、E01 の Log Loss は 0.57243 から 0.56959 に下がった。共有可能な側で既出質問が0件のペアは 0.45292 → 0.45335、1件は 0.55335 → 0.54503、2件は 0.83359 → 0.83015。
  - 連結成分で分けた主 CV の検証ペアを固定すると、同一ペアを除外した時点で共有可能な質問がゼロになる。質問共有を調べる補助診断ではノード分割で共有可能な学習候補を確保した。
  - seed 42 の単一診断で、学習行の構成も変わる。対象は単語 TF-IDF 類似度と長さを使うロジスティック回帰で、採点対象となる Kaggle テストの質問共有率は不明。[実験記録](../competitions/045-quora-question-pairs/experiments.jsonl) の E01-shared・E01-shared-r2。

- #016 PetFinder（譲渡速度の順序5クラス、QWK）
  - 公式配布の学習・公開テストで保護者 ID の重複は0。学習の保護者 5,595 組を完全一致画像で結合すると 5,558 グループになった。保護者 ID だけで分けると、同じ画像が fold をまたぐ可能性がある。
  - 未知の保護者を対象とする主 CV では、この連結グループを分割単位にした。行単位分割とのスコア差は未測定。[検証手順と EDA](../competitions/016-petfinder-adoption-prediction/README.md)

- #093 MoA（表形式の多ラベル分類、Log Loss）
  - 同じ独立 L2 回帰で化合物単位の 5 分割は 0.035158、行シャッフル 5 分割は 0.026924。行分割では fold ごとに 2,330〜2,362 化合物 ID が学習・検証間で重複した。
  - 未知化合物への汎化を見るため化合物単位を主分割にした。分割ごとの陽性ラベルの構成も異なり、公式テストの化合物 ID は非公開。 [検証と振り返り](../competitions/093-lish-moa/report.md)

- #074 Global Wheat Detection（小麦の穂の物体検出、画像単位の検出スコア）
  - 公式学習画像のうち撮影元が分かる3,373枚を同じ Faster R-CNN で採点した。撮影元を分けた3-fold の OOF は 0.445057、画像単位のランダム3-fold は 0.612980（+0.167923）。
  - ファイル内容の完全重複と、差分ハッシュの距離4以下の近重複候補は0件だった。撮影元によって穂の密度とサイズが異なった。分割変更で撮影元の共有に加え、fold ごとの学習画像数と構成も変わった。
  - 全学習画像で再学習したベースラインの Late Submission は Public 0.5459 / Private 0.4791。 [実験記録](../competitions/074-global-wheat-detection/experiments.jsonl)

- #094 OpenVaccine（RNA 塩基ごとの分解予測、MCRMSE）
  - 学習配列には同じ配列の小さな変種が多い（5-mer 最近傍 Jaccard の中央値 0.57）。5-mer Jaccard ≥ 0.35 の連結成分で GroupKFold にすると、同じ位置窓 LightGBM の OOF は 0.31993、分子単位のランダム 5 分割は 0.29940（0.02053 楽観）
  - 外部評価（公開済み Private 正解でのローカル採点）は 0.43284 と 0.43473 でほぼ同じ。クラスタ分割でも CV との差は 0.113 残った。評価先が別の収集ラウンドで、分割で縮むのは差の一部だけ（K048）

## 適用条件

- グループの中の行がほぼ重複していて（動画のコマ、同じ患者の複数枚など）、test のグループが学習と重ならない場合
- #074 では近重複候補が検出されなかった画像群でも、未知の撮影元を分けると評価が下がった。画像の密度や物体サイズなどが撮影元ごとに異なる場合も、予測先に合わせてグループを分ける。
- #050 の要約採点では、同じ4課題・7,165行を評価し、正規化後に完全一致する要約の学習・検証間共有を防いだ。課題を分けた Ridge の OOF MCRMSE は 0.85492、行単位ランダム分割は 0.72724。未知課題を評価する場合は課題を分割単位とする。
- 事前の診断として、単純な特徴（縮小画像など）の 1-NN の正解率を、グループ単位とランダムの分割で比べる。差が大きければグループ単位の分割が必須
- 時系列での楽観（K007、0.025〜0.045）とは仕組みが違う。こちらは補間ではなく、ほぼ同じ行の記憶
- 「桁違いの楽観・採否逆転」を実測した条件は#060の動画フレーム。#083の短い発話にはそのまま一般化しない。

## 未検証

- #083での逆方向の差が、別seed・別モデル・長い学習でも生じるか。収束・正則化・抽出比率の寄与
- モデルの容量（大きいモデルほどランダム分割で良く見えるか）、epoch 数の選択への影響
- test のグループの一部が学習と重なる場合（GroupKFold が楽観にも悲観にもなりうる）

## 次の検証機会

- 患者・撮影者・動画単位のグループがある画像・音声・医療のコンペで、同じ行を両方の分割で評価し、採否が逆転するかを確かめる
