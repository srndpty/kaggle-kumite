# K012: test の中の似た行と予測を平均すると logloss が下がる。ただし効果は提出と同じ形で測る

- 状態: 仮説
- 分類: 後処理

## 仮説

test が同じグループ（同じ人の動画のコマなど）のほぼ重複した行の集まりなら、ラベルを使わずに test の中で近傍を探し、近傍の予測と平均できる。1 行ごとの予測の揺れ（自信のある単発の誤り）が均されて logloss が下がる。モデルの平均と同じく「揺れを均す」処理なので、fold 平均などと効果が重なる。

## 観測

- #060 State Farm（画像 10 クラス、logloss）: 1 位・3 位が使った手法（1 位は VGG16 の pool5 特徴で近傍 10 枚の重み付き平均、単体のスコアで約 0.10〜0.12 改善。第三者の要約による）
  - CV での再現: 近傍は同じ fold の検証画像の中だけで探す（test で test の中だけを探すのと同じ形。ラベルを使わない）
  - 凍結 ResNet50 の特徴で選んだ近傍 10 枚との単純平均: OOF 0.386 → 0.272（-0.114、26/26 人で改善）。画素の小画像で選ぶと -0.102
  - 正解率はほとんど変わらない（0.890 → 0.905）。改善は確率の質（上位 5% の行が損失に占める割合 61.5% → 51.8%）
  - **Late は CV の約半分**: Private 0.268 → 0.217（-0.050）、Public -0.060
  - 提出と同じ形の入れ子の疑似テストで説明できた: 単一モデルの予測には -0.124、4 モデルの平均には -0.053
  - 学習し直した 1 モデルに近傍の平均をかけると、fold 平均 + 近傍とほぼ同じ（Private +0.010、Public -0.004）。近傍の平均が、モデルの平均の代わりに揺れを均す

## 適用条件

- test の中にほぼ重複した行（同じグループの連続したコマなど）が多い場合。事前に test の中の最近傍の類似度を見る（#060 は相関の中央値 0.990）
- CV で測るときは、近傍を検証行の中だけで探す。学習行を近傍に入れると、ラベルの付いた行（同じ fold の学習行）と混ざり、test と形が違う
- 効果の大きさは、提出と同じ形（fold 平均）の予測で測る。OOF（単一モデルの形）では過大に出る（K002 と同じ構造）

## 未検証

- k・重み（類似度による重み付け）・特徴の選び方の影響
- 近傍が同じグループに収まっているか（学習データで同じグループの割合を測れる）
- 予測が鋭いモデル（大きいモデル・長い学習）での効果
