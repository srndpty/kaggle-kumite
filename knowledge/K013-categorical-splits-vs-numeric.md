# K013: 木モデルのカテゴリ分割と数値分割を比較する

- 状態: 仮説
- 分類: 前処理 / モデル

## 仮説

名義カテゴリでも、モデルのカテゴリ分割が常に数値分割より良いとは限らない。

## 観測

Porto Seguro の LightGBM で、カテゴリ列を数値として使うとfold平均Giniが3 seedすべて改善。E04−E01は+0.015781 / +0.017050 / +0.015331、平均+0.016054。自力の事前予想（数値扱いで悪化）と逆だった。

## 適用条件

匿名テーブル57特徴、陽性率3.64%、層化5分割、31葉、learning_rate=0.05、AUC early stoppingという今回の設定。カテゴリ方式以外を固定した。カテゴリ辞書は学習fold内だけで作った。

## 未検証

原因が正則化・カテゴリ分割の実装・データ内の順序のどれかは不明。意味ある順序が存在すると証明したわけではない。one-hot、他モデル、カテゴリ数の違いは未検証。3 seedは同じデータの再分割で、独立データでの再現ではない。

## 次の検証機会

匿名カテゴリを含むBNPや信用リスク系コンペで、カテゴリ分割・数値分割・one-hotを比較する。
