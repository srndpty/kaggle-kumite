# K016: 単語TF-IDFに文字特徴を追加すると分類性能が改善した

- 状態: 仮説
- 分類: 特徴量 / モデル

## 仮説

単語単位の語彙だけでなく文字n-gramを使うと、単語内の部分的な一致からも分類できる。

## 観測

#041 Jigsawの単語unigram TF-IDF+ラベル別LRにchar_wbの3〜5gramを追加すると、seed42のfold平均macro AUCは0.979929→0.985127（+0.005198）。3/3foldで改善し、ラベル平均OOF LogLossも0.054970→0.048473へ改善した。一方、単語bigramの追加はAUC 0.978583へ悪化した。

seed43でもfold平均macro AUCは0.979964→0.985175（+0.005211）。2つの分割seedで改善方向と大きさが揃った。ただし同じコンペ内の確認なので、状態は「仮説」のままとする。

## 適用条件

英語のWikipediaコメント・6ラベル分類。文面重複をグループ化した多ラベル層化3分割。語彙・IDFは学習foldのみでfit。min_df=3、単語最大10万・文字最大15万、sublinear_tf、各行列のL2正規化、LRのC=1。

## 未検証

改善が綴りの変形への頑健性によるかは未検証。特徴行列を結合しても再正規化しないので、特徴量の拡張と正則化の実効的な変化を分離できていない。文字範囲・語彙上限・Cの別設定や他言語への一般化は測っていない。

## 未検証

綴りの変形を加えた対照データでの頑健性、他のNLPデータへの一般化、正則化Cや特徴数上限を揃え直した場合の差。E03は単語・文字を別々にL2正規化して結合し、結合後は再正規化していないので、効果を語彙のカバー範囲だけに帰属できない。
