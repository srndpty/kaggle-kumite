# K024: 極端値の発生確率と条件付き平均を分ける回帰

- 状態: 仮説
- 分類: モデル / 評価

## 仮説

連続目的値が通常群とまれな極端値群の混合なら、群の発生確率と群別の条件付き平均から求める期待値で二乗誤差を減らせる可能性がある。

## 観測

Elo では `target < -20` のカードは 1.09% だが、E01 の OOF 二乗誤差の 77.87% を占めた。同じ入力を使って群別の平均を確率加重した E04 では、通常群 RMSE は 1.81658 から 1.81423 に下がり、極端値群 RMSE は 32.41757 から 32.45304 に上がった。全体 RMSE は 3.84063 から 3.84281 に上がった。

## 適用条件

カードを1行とする RMSE 回帰。極端値の定義は外側評価前に固定し、群の確率と平均は各 fold の学習行だけで推定する。群の頻度と二乗誤差への寄与を併記すると、全体差をどちらの群が支配したかが分かる。

## 未検証

群の確率較正、月別特徴と群別モデルの併用、内側 CV を使った分類モデルの調整、別の極端値率や目的値分布への一般化。

## 次の検証機会

低頻度の極端値を含む回帰で、同じ特徴を使い、単一回帰と確率加重を固定分割で比較する。確率の較正誤差と群別 RMSE も記録する。
