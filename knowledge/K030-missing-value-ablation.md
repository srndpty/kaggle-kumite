# K030: 欠損の扱いを固定 fold で比較する

- 状態: 仮説
- 分類: 前処理 / 検証

## 仮説

欠損率の高い表で、木の欠損分岐、欠損指示、欠損カテゴリの変更が確率予測を改善するかは、個別に検証する必要がある。

## 観測

BNP Paribas の LightGBM で、数値の欠損分岐は中央値補完に対して OOF Log Loss が −0.000212。行単位のペア bootstrap 95% 区間は [−0.000608, 0.000168]。数値の欠損指示、カテゴリ欠損の独立化でも改善を確認できなかった。

## 適用条件

学習行の 84.47% に少なくとも 1 個の欠損がある匿名化表。seed 42 の層化 5 fold、CPU LightGBM 350 木、学習 fold だけで補完値とカテゴリ辞書を決定した。

## 未検証

木の深さ、seed、グループ分割、欠損パターンの組み合わせで効果が変わるかは未検証。再標本化は行単位。

## 次の検証機会

欠損機構が異なる別の表形式コンペで、同じ比較を行う。
