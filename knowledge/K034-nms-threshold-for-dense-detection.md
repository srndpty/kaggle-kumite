# K034: 密集した物体の検出では NMS の見逃しと誤検出を併せて測る

- 状態: 仮説
- 分類: 後処理

## 仮説

NMS の IoU 閾値を上げると、隣接する物体を拾いやすくなる一方、同じ物体への重複予測も残りやすくなる。見逃しと誤検出を分けて集計すると、スコア変化の理由を確認できる。

## 観測

#074 の Faster R-CNN で学習済みの重みを固定し、推論の NMS IoU を 0.50 から 0.65 に上げた。穂が51本以上ある1,272枚では、IoU 0.50 の見逃しは 19,680 → 19,042 件、誤検出は 13,785 → 21,372 件。全画像の OOF は 0.445057 → 0.406032 だった。

## 適用条件

穂が隣接する圃場画像の単一クラス検出。信頼度閾値0.25、最大検出数300件、撮影元を分けた3-fold で比較した。

## 未検証

誤検出のうち重複予測が占める割合、別の信頼度閾値との組み合わせ、別の検出器・データへの再現性。

## 次の検証機会

密集物体の別タスクで、重みを固定して NMS の IoU 閾値を変え、物体密度ごとの見逃しと誤検出を比較する。
