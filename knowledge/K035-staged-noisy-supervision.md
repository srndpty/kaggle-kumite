# K035: 弱ラベルを使う順序を同じサンプル数で比較する

- 状態: 仮説
- 分類: モデル

## 仮説

弱ラベルを使って特徴を学び、信頼度の高い対象ドメインのラベルで仕上げると、両方を学習の最後まで混ぜるよりタグ順位が改善する場合がある。

## 観測

#084 の 1,600 更新、batch 32 で、noisy を毎回25%混ぜる E02 と、最初の400更新は noisy のみ、残り1,200更新は curated のみにする E05 を比較した。延べサンプル数は両方で同じ。curated OOF の lwlrap は **0.39898 → 0.40982**。差 +0.01083 のクリップ単位ペア bootstrap 95%区間は [+0.00154, +0.01945]。curated のみの E01 に対しても +0.01421 だったが、2秒以下と正例50件以下のタグでは下回った。

## 適用条件

80タグの可変長音声、2秒窓の小型 CNN、BCE、curated 検証データ。noisy と curated では音源の出所・音声長・ラベル品質が異なる。

## 未検証

別 seed、弱ラベルの比率や事前学習回数を変えた場合、別データでの再現性。ドメイン差、ラベルの誤り、音声長の寄与は未分離。

同じ構成間の改善は外部評価で未検証。全データ再学習の単一 E05 は Private 0.26984、3 fold 平均の E01 は 0.37736 で、比較には提出モデルの構成差も含まれる。

## 次の検証機会

#085 などの音響タスクで弱ラベルの使用量を固定し、混合学習と段階学習を比較する。録音場所やタグ頻度ごとの効果も測る。
