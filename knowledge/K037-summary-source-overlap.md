# K037: 原文との語句一致率を要約評価の特徴に使う

- 状態: 仮説
- 分類: 特徴量

## 仮説

要約の長さや文の構造に加え、推論時に参照できる原文との語句一致率を使うと、課題が変わっても内容や表現の評価に役立つ。

## 観測

#050 では長さと文構造だけの Ridge に、要約の unigram・bigram のうち原文に出現する割合を加えた。4課題を一つずつ保留した OOF MCRMSE は 0.85492 → 0.75594。全4課題で改善し、内容 RMSE は 0.69919 → 0.66477、表現 RMSE は 1.01064 → 0.84712。要約の TF-IDF または設問だけとの単語一致率を加えた試行は悪化した。

## 適用条件

原文が各要約に対応し、学習時・推論時とも参照できる英語の要約採点。観測条件は文章構造を基準とする Ridge と、未知課題を保留した検証。

## 未検証

unigram と bigram 個別の効果、原文をコピーした要約や言い換えへの挙動、意味類似度を使う特徴との比較。

## 次の検証機会

原文と回答が対応する別の文章採点で、回答の長さを固定した誤差分析と、語句一致率の単独比較を行う。
