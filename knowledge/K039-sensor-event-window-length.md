# K039: センサーの時間窓はイベント種別ごとに効果を確かめる

- 状態: 仮説
- 分類: 特徴量 / 時間窓

## 仮説

瞬時値に短い時間窓の統計を加えると、ウェアラブルセンサーのイベント検出で運動の持続や変化を捉えやすくなる。窓幅と時点の前後どちらを使うかは、イベント種別ごとに検証する。

## 観測

#091 では、軸別の平均・標準偏差を過去1秒から求めると、瞬時値の OOF 平均 AP は 0.09644 から 0.12935 に上がった。過去3秒に延ばすと Turn は 0.33322 から 0.36494 に上がり、StartHesitation は 0.03208 から 0.02338 に下がった。1秒窓を中央揃えにしても StartHesitation の AP は改善しなかった。

## 適用条件

3軸加速度の歩行凍結ラベルをサンプル単位で分類した。100 Hz と 128 Hz の収録で窓の長さを秒単位で揃え、被験者単位の同じ5 fold で、CPU LightGBM の学習設定を固定した。3秒窓の採用根拠は3クラス平均 AP であり、希少な StartHesitation は陽性行の77.8%が1人に集中していた。

## 未検証

異なる被験者集団やセンサー、ニューラル系列モデルでの効果。長い窓の効果を持続時間とノイズ低減のどちらに帰属できるか。外部評価での再現性。

## 次の検証機会

別の姿勢・動作認識コンペで、同じ分割に対して瞬時値・短窓・長窓を固定比較し、対象イベント別の AP を確認する。
