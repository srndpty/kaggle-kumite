# K040 元尺度 MAE の回帰で L1 と L2 を比較する

- 状態は仮説
- 分類はモデル

## 仮説

MAE を使う右裾の長い回帰では、元尺度 L1 で学習すると大きな残差が二乗で重み付けされなくなり、典型的な損失帯の過大予測を抑えられる。

## 観測

#011 の固定 5-fold GroupKFold で、LightGBM の学習損失を元尺度 L2 から L1 に変更すると OOF MAE が 1188.21 から 1159.18 に下がった。下位 25% と中央 50% の MAE は改善し、上位 1% は 7815.20 から 9677.83 に悪化した。対数変換と L2 の組み合わせは全体で 1152.20 だった。

## 適用条件

保険金支払額のような右裾の長い目的変数で、行を等しく重み付けする元尺度 MAE を評価する場合に確認した。

## 未検証

他データ・他モデルへの一般化、手法間の順位の seed 依存、大口の誤りに追加の費用がある指標。L1 の外部スコアは未計測。

## 次の検証機会

別の元尺度 MAE 回帰で、L1、L2、変換後 L2 を分割と特徴量を揃えて比較する。
