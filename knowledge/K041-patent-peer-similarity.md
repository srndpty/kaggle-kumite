# K041: 同じ基準語句・文脈の他候補から類似度を補う

- 状態: 仮説
- 分類: 特徴量 / テキスト

## 仮説

同じ基準語句・文脈に対する複数の候補を一括で採点する場合、他候補との文字列類似度から候補集合の傾向を捉えられる。

## 観測

#054 の Ridge に同一 anchor・CPC の他候補の文字 TF-IDF コサイン平均を加えると、未知 anchor を保留した5-fold の OOF Pearson が 0.48722 から 0.48840 に上がった。連結成分単位のペア・ブートストラップ95%区間は差 [+0.00032, +0.00201]。複数 CPC に現れるペアの MAE は 0.17560 から 0.17627 に上がった。

## 適用条件

候補がバッチで参照できる特許語句の類似度回帰。TF-IDF の適合は学習 fold 内に限定し、候補集合の集計は学習・検証・提出の各バッチ内で独立に行った。集計では現在行を除外し、ラベルは参照しない。

同じ行でも同時に渡す候補が変わると予測が変わる。#054 の OOF では候補数中央値が 23、公開テストでは全群が単独で特徴値がゼロだった。OOF の単独 151 行では追加後の MAE が 0.12959 から 0.13595 に上がった。適用時は予測バッチで候補集合を揃え、候補数別に効果を確認する。

## 未検証

候補生成の方法や候補の構成が異なる場合の効果。非公開テストの候補数分布と公式提出の E04 と E05 の直接比較。意味埋め込みで同じ集計をした場合の効果。
