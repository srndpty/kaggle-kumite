# K044: 学習行の新しさによる重み付けを週別 Gini の傾きで検証する

- 状態: 仮説
- 分類: モデル / 検証

## 仮説

直近の学習行を重くすると、古いデータ分布の影響が弱まり、将来期間の識別力の低下を緩和できる。

## 観測

#005 で申込週の差に半減期26週の重みを掛けると、3窓平均の安定性スコアは 0.50804 → 0.46105。最初の窓では平均週別 Gini が 0.56424 → 0.55707、傾きへのペナルティが −0.20101 → −0.30062 だった。最初の窓の悪化の大半は週別 Gini の傾きに対応した。第2窓は平均 Gini が改善したが、残差のばらつきの増加で安定性スコアは低下した。

## 適用条件

静的属性と過去申込特徴による CPU LightGBM。各窓以前を学習に使う連続13週の3窓を固定し、重みだけを変えた。安定性指標では、負の傾きに係数88のペナルティが掛かる。

## 未検証

半減期を変更した場合、別期間での再現、重み付けの外部評価。

## 次の検証機会

時点が進むと入力の分布が変わる別コンペで、学習時の重みだけを変え、予測先までの期間ごとに識別力を比較する。
