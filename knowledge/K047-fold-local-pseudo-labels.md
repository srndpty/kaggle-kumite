# K047: test への疑似ラベルは fold 内の教師で作り、CV でリークなしに評価する

- 状態: 仮説
- 分類: 学習 / 検証

## 仮説

test の入力が学習と離れている場合、test に疑似ラベルを付けて学習に加えると、test 側の入力分布を学べて改善する。全学習行で作った教師の疑似ラベルを CV に使うと、検証ラベルの情報が疑似ラベル経由で学習側に入る（K004 と同じ経路）。fold ごとに、その fold の学習行だけで教師を作れば、CV で効果を測れる。

## 観測

#094 OpenVaccine（MCRMSE）。E06（双方向 GRU + bpp + 逆分散重み + 5 目的）と同じ設定の教師を fold ごとに学習し、test 3,634 配列（長さ 107・130）の全位置に疑似ラベルを付けた（E07）。

- CV 0.25677 → 0.25112（−0.00565、クラスタ bootstrap 95% 区間 [−0.00694, −0.00414]、5/5 fold で改善）
- Late Submission の Private は 0.37334。E06 のローカル Private は 0.37560 で、差は −0.00226。外部での改善は CV の半分以下だった
- 重みの落とし穴: E07 は疑似ラベルの要素重みを「学習行の重みの中央値 × 0.5」にしたつもりだった。しかし疑似ラベルは別バッチで、損失はバッチ内で重みの和により正規化されるため、一律の重みは相殺され、寄与は実効的に 1 倍だった
- 正規化後の損失に係数 0.5 を掛ける形に直した E08 は、CV 0.25092（E07 との差 −0.00020、95% 区間 [−0.00196, +0.00138]）で実質同点。E08 は最終選定と Private 観測の後の追加実験

論文（主催者と入賞者の共著）によると、上位チームの多くが疑似ラベルを決め手に挙げていた。

## 適用条件

- test の入力（配列）が配られ、学習と分布が違う場合
- 疑似ラベルの損失の係数は 1 倍と 0.5 倍で実質同点だった。この範囲では強さに鈍感
- 疑似ラベルを別バッチにするときは、寄与を要素重みではなく損失の係数で変える（重みの一律倍はバッチ内の正規化で消える）

## 未検証

- 0.5 倍より小さい係数（0.1 など）、反復回数、教師のアンサンブル化の感度
- 全学習行の教師で作った場合に CV がどれだけ楽観になるか（リークの大きさの実測）
- Private の改善が CV より小さい理由

## 次の検証機会

- test 入力の分布が学習と異なる系列・画像コンペ
