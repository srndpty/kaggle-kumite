# K048: 評価先が別の収集ラウンドなら、CV と外部評価の差は分割の工夫では埋まらない

- 状態: 仮説
- 分類: 検証

## 仮説

評価先のデータが、学習データとは別の時期・別の設計ラウンドで集められている場合、学習データの中でどう分割しても評価先の条件は再現できない。系列長などの目立つ違いを差の原因と考えがちだが、まず位置・属性ごとに外部誤差を分解して確かめる。

## 観測

#094 OpenVaccine。学習と Public は同じ設計ラウンド（長さ 107）、Private は大会開始後に集めた別ラウンド（長さ 130、学習ラベルのない位置 68〜90 も採点）。公開された Private 正解で、各 run の test 予測をローカル採点した。

- 最終モデル（E07）: CV 0.25112、Public 0.25489、Private 0.37334。CV と Public はほぼ一致し、Private だけが 0.12 悪い
- 位置で分けた Private: 学習で見た位置（0〜67）0.39264、外挿位置（68〜90）0.30904。**外挿位置の方が誤差が小さい**。全 run で同じ向き
- Private の配列は学習から遠い（5-mer 最近傍 Jaccard の中央値 0.236、学習配列どうしは 0.57）。Private ラベルの散らばりも学習より大きい（列別標準偏差 0.47〜0.74、学習 SN=1 は 0.46〜0.52）
- 類似度クラスタ分割（検証→学習の最近傍中央値 0.261）でも、E00 の CV と Private の差は 0.113。ランダム分割では 0.135

## 適用条件

- 評価先が後から追加収集されたデータで、Public と Private の母集団が違うことが分かっている場合

## 未検証

- 配列の新しさと、測定ラウンドの違い（ラベルの散らばり）の寄与の分離
- 分割を変えるとモデル選定の結論が変わるか（#094 では CV と Private で順位が入れ替わった組が 2 つあったが、差は 0.002 程度で単一 seed）

## 次の検証機会
