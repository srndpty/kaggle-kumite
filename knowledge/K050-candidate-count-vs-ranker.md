# K050: 候補を変えると、再ランキングの教師グループも変わる

- 状態: 再現
- 分類: 推薦 / 評価

## 仮説

候補内に正解のあるグループだけで再ランキングを学習すると、候補の作り方の比較に教師グループの変化が混ざる。候補 Recall と最終指標の差を候補数だけに帰属できない。

## 観測

#033 で候補を100件から300件に広げると（E08）、3窓の候補 Recall は 0.130 / 0.124 / 0.141 から 0.242 / 0.233 / 0.251 に、MAP の上限は 0.150 / 0.142 / 0.159 から 0.265 / 0.251 / 0.269 に上がったが、LambdaRank の OOF MAP@12 は 0.030936 → 0.029114 に下がった。

このとき教師の顧客は 20,778〜23,221 人から 32,834〜37,085 人に増え、正例率は 1.35〜1.36% から 0.53〜0.54% に下がった。候補300件のまま教師の顧客だけを候補100件のときと揃えた E10 は 0.030822 で、E08 から +0.001708（95%区間 +0.001448〜+0.001982）、候補100件との差は −0.000113（−0.000332〜+0.000115）。E08 の低下の大半は教師の顧客の変化に対応し、候補数だけを変えた差は区別できなかった。

候補 Recall が上がっても MAP が上がらない点は E10 でも同じ。本人の購入をさかのぼる期間を28日から365日に伸ばした E06 は、Recall が 0.124 / 0.119 / 0.134 に下がったのに MAP は 0.030936 → 0.033484 に上がった。

#040 OTTO では40候補と同じ教師を使い、候補を100件にすると OOF 加重 Recall@20 が 0.48521 から 0.48643 に上がった。候補から到達可能なスコアの改善は約0.0071だった。
100候補のまま教師を広げると、セッションと行動の組は2週合計15,487組から15,776組に増えた。OOF の差は −0.00020（セッション対応付き95%区間 −0.00026〜−0.00013）で、教師グループの効果は #033 より小さかった。

## 適用条件

- #033 は `weekly-v1` の3窓（7日）、直前1週の教師、ラウンド数200固定の LightGBM LambdaRank。追加した候補は人気の順位だけで決まる商品。
- #040 は `weekly-prefix-v1` の2窓（7日）、疑似切断した直前週の1%の教師セッション、ラウンド数100固定の行動別 LambdaRank。追加候補は直近商品と行動別人気の順で決める。

## 未検証

加わった教師の顧客がなぜ順位を悪くするか。正例率の低下の影響、負例の間引き、特徴やラウンド数を候補数に合わせた場合、人気以外の検索器で候補を増やした場合。E06 の改善のうち教師の顧客の変化による分。

## 次の検証機会

候補の追加元を人気順から共起や埋め込みに変え、教師グループを揃えた比較を行う。
