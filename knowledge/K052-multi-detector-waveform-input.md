# K052: 複数検出器の波形を一緒に入力する

- 状態: 仮説
- 分類: 特徴量 / 信号

## 仮説

同じイベントを異なる雑音の下で観測する検出器の波形をまとめて入力すると、単一検出器より信号を識別しやすくなる。

## 観測

#092 で Hanford の単一チャネルに Livingston と Virgo を追加すると、全体 OOF AUC は 0.73009 から 0.78815 へ上がり、3 fold すべてで改善した。同じ 3 台構成で、学習時に Hanford と Livingston を行ごとに確率 0.5 で入れ替える追加実験では AUC が 0.78815 から 0.78642 に下がった。

## 適用条件

各サンプルについて同じ 2 秒区間の波形が 3 検出器分揃う条件で、25〜500 Hz の帯域制限と fold 学習側で推定した検出器別白色化を使用した。モデルは時間軸の 1D CNN で、チャネルは入力層から統合した。

## 未検証

Livingston と Virgo 個別の寄与。検出器間の時間差の明示的な処理、検出器が欠けたデータ、検出器別エンコーダーの効果。

## 次の検証機会

異なる雑音を持つ複数センサーが同一イベントを測る課題で、単一入力と同時入力を固定分割で比較する。
