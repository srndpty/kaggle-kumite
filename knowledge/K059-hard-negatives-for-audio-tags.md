# K059: 録音中の誤検出注釈を使う負例置換

- 状態: 仮説
- 分類: 音声 / 学習データ

## 仮説

誤検出注釈に対応する音を種別の負例に使うと、録音全体で紛らわしい種の順位を下げられる。

## 観測

#085 で弱い背景負例の半数を種別の誤検出窓に置換したところ、録音単位の OOF lwlrap は 0.347081 → 0.305969。ペア bootstrap の95%区間は差 −0.057007〜−0.026382 で、３ fold すべてで低下した。

## 適用条件

32 kHz の log-mel、５秒窓、小型 CNN、録音単位の３ fold。背景窓では負例重みを全24種に配分し、誤検出窓では同じ総重みを注釈対象種だけに割り当てた。同一種の真陽性に重なる誤検出窓は除外した。

## 未検証

E01 は背景の抽出頻度に加え、抽出元の背景プール自体も半減させた。背景音の多様性低下、誤検出音の内容、種別監督の変化の寄与は分離していない。背景プールを維持した置換、置換率、総損失重みは未検証。
