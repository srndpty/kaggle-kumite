# K060: 同じエッセイの他の論証を文脈に使う

- 状態: 仮説
- 分類: テキスト / 文脈

## 仮説

論証を単独で分類する際に、同じエッセイの他の論証本文を追加すると、主張や根拠のつながりを判定に利用できる。

## 観測

#052 で対象論証の単語 TF-IDF に、同一エッセイの他の論証だけから作った TF-IDF を追加すると、OOF LogLoss は 0.805329 → 0.751580。エッセイ単位のペア bootstrap 95%区間は差 −0.061125〜−0.046781。16語以下でも −0.04700 だったが、効果は短い論証に集中しなかった。

最終選定後の Kaggle Late Private も 0.79778 → 0.74798 に改善した。

## 適用条件

推論時にもエッセイ内の論証要素が揃う３クラス分類。エッセイ単位の５ fold で、対象論証を文脈から除外し、各 TF-IDF は学習 fold だけで適合した。

## 未検証

周辺論証が一部欠ける場合、題材・エッセイ全体の品質と論証間のつながりの寄与、論証種別との組み合わせ、他データでの再現性。
